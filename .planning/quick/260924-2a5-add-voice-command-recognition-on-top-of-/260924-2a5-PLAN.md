<objective>
Swap `transcribe.js` off the Web Speech API onto a fully offline, on-device Whisper engine, then
add a small on-device intent classifier that maps every completed transcript to one of 5 fixed
voice commands (start recording, stop recording, save file to \<name\>, start microphone, start
landmarks), gated by a confidence threshold between direct execution and a clarification prompt,
wired to `main.js`'s existing button actions extracted into named functions.

Purpose: `hands-face-voice/` currently transcribes speech only to display it, and sends that audio
to Google's cloud speech service in Chrome — both violate the workstream's local-only,
offline-privacy stance and leave transcription inert (text appears, nothing happens). This plan
makes the transcript actionable, on-device, end to end.

Output: `transcribe.js` rewritten onto `@huggingface/transformers`'s `automatic-speech-recognition`
pipeline; a new `commands.js` implementing embedding-based intent classification; `record.js`
gaining a one-shot custom base-name override; `main.js`'s five click handlers extracted into named
functions and wired to voice dispatch; `index.html` updated with the CDN import, an accurate
transcription caveat, and a command/clarification status element.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser page -> jsDelivr/HF Hub CDN | Third-party library code (`@huggingface/transformers`) and model weights (Whisper, all-MiniLM-L6-v2) are fetched over the network and executed as WASM/JS in the page |
| Spoken voice input -> command dispatch | A noisy, machine-transcribed signal (Whisper output, then a cosine-similarity guess) drives real actions: starting the camera/mic, starting/stopping a file-system recording |
| Transcribed text -> filesystem name | The "save file to \<name\>" slot is free-form speech text used as a browser File System Access API base name |

| T-2a5-02 | Tampering | Whisper mis-transcription or classifier misfire driving the wrong command | medium | mitigate | `CONFIDENCE_THRESHOLD` gate: only scores >= threshold execute directly; anything lower produces a non-executing clarification prompt instead |
