<objective>
Add `layout` as a third lock aspect in the Phase 2.4 lock model, so that Phase 2.5's `place` verb has a layout lock to check. Its defaults must be the same as the `text` aspect's, and no existing command may become gated on it.

Kaelen's decisions for this quick task are locked. They are labelled here for traceability:
- **Q-01 (key names):** the keys are `lock.layout` and `lock.layout.allow`, produced by the existing `lockKey` / `allowKey` template (`lock.<aspect>`, `lock.<aspect>.allow`).
- **Q-02 (defaults mirror text):** a note not created by an agent (a person, the Obsidian vault/bridge, another plugin) starts layout-locked to its creator. An agent-created note starts open to agents. Malformed values fail closed, only the exact `open` unlocks, and the allow list is honoured exactly as it is for text.
- **Q-03 (named constant, conditional):** add a named default-policy constant for layout only if that is how the text/delete defaults are expressed. **Resolution, recorded here and in the SUMMARY:** text's non-agent default is not a named constant. It is the unconditional `lockedToCreator` fall-through in `resolveLock`. Only delete has one (`NON_AGENT_NOTES_DELETE_LOCKED`, 02.4 D-05), and agent-created notes share `AGENT_NOTES_OPEN_TO_AGENTS` (02.4 D-06) across all aspects. Mirroring text therefore means **no new constant and no new `LockPolicy` field**. Layout, like text, has no toggle. `DEFAULT_LOCK_POLICY` and its existing test stay unchanged. The locks.ts doc comment says this explicitly, so that adding a toggle later is a visible one-field change.
- **Q-04 (no gating):** do not gate any existing command on layout. Do not touch `notes.ts` (update/rename/delete paths), `schemas.ts`, `agent-tools.ts` or any agent tool text. Phase 2.5 `place` is the first caller.
- **Q-05 (rank):** `rank` stays deferred. Update the "deferred" comment to name only `rank`.
- **Q-06 (tests first):** extend `locks.test.ts` test-first, red then green.

Purpose: Phase 2.5 D-15 needs a placement lock where "a user-made note cannot be moved by an agent by default", plus `lock.layout.allow` and the `open` value. This supplies that resolver without changing any behaviour that exists today.
Output: `locks.ts` with the widened aspect union and updated doc comments, and `locks.test.ts` with a layout test block and two real-kernel non-gating tests.
