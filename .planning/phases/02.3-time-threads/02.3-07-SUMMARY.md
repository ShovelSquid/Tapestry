- **No side-view scenario exists in the `--bench`/`--shots` harness.** `thread-bench.cjs`/`bench-entry.ts` were not in this plan's file list, so the week-scale "evenly spaced dots" claim (D-16 precision) is proven by the same float32-exactness arithmetic RESEARCH Pattern 5 documents and `side-view.ts`'s own header repeats, not by an actual captured screenshot this session. - **`DateScrubber`'s `dailyLetterCounts` buckets a session's full letter count onto its own start day.** A session spanning midnight is counted entirely on the day it started, not split proportionally across the days it touches — a documented simplification for a navigational aid, not a byte-exact ledger.
- **Escape returns to now but does not chain into closing the whole thread view on a second press.** UI-SPEC's keyboard map row reads "Esc: Return to now, then close the thread view" as one combined description; this plan implements the "return to now" half fully (from a past stage, or from the side view) but a second Escape press does not additionally close the overlay — a person still uses the explicit "Close thread view" button for that. - **`A` ("Show each author on its own line") and `Opt`-hold (author underlay reveal) are documented no-op seams in the keyboard handler.** D-23's strand drag-apart and D-21's underlay reveal have no rendering to toggle yet (no twisted-strand visual exists in the stage); `NAV_KEYS` maps the key, and `handleStageKeyDown`'s own case comment names exactly what a later plan wires it to.

None of the above are placeholder UI shown to a user as if it were real data; each is either an honestly-scoped simplification with a documented reopening seam, or explicitly out-of-scope later-plan work (D-20..D-23 agent strands are this phase's own next plan per RESEARCH's architecture map).
