## What a thread is and saves

**Q: Kaelen has described a thread as "a single note" and as "a series of notes with one central node". Which is closer?**

| Option | Description | Selected |
|--------|-------------|----------|
| One note; sessions are entries (Recommended) | One growing document; each time-in → time-out stretch shows as an entry | |
| Central note drops real notes | Each session or link becomes its own small note on the thread | |
| One note, the line is its history | The document only; the line shows when each letter arrived | |

**User's choice:** Free text: "It's a central one growing document, with the line showing when each letter arrived."

**Q: When text is deleted or rewritten, what does the line show?**

| Option | Description | Selected |
|--------|-------------|----------|
| Deleted letters stay, marked (Recommended) | Faded or struck at the typed moment, plus a deletion mark | ✓ |
| Only surviving letters show | Deletions stay in history but aren't drawn | |
| Deletion marks only | Letters vanish; a mark shows the deletion | |

**Q: How do keystrokes with times look in the .tree file?**

| Option | Description | Selected |
|--------|-------------|----------|
| Small commits as you type (Recommended) | About every ⅓ s of typing, typed and deleted letters with time offsets | ✓ |
| One commit per session | Text change plus a timing list per session; risks losing a session on crash | |
| Timings in a sidecar file | .tree keeps text; timings in `world.tree.timing` | |

**Q: Is the thread's document a full note, and do those events show on the line?**

| Option | Description | Selected |
|--------|-------------|----------|
| Full note; links and formats marked (Recommended) | Same editor; link and format actions drop markers on the line | ✓ |
| Full note, only letters on line | Same powers; the line shows letters, dots and dashes only | |
| Plain text only | No formatting or passage links | |

**Q: A pasted paragraph: how does it land on the line?**

| Option | Description | Selected |
|--------|-------------|----------|
| One moment, marked as pasted (Recommended) | Tight cluster at the paste moment with a paste marker | ✓ |
| A single marker with a label | One marker; hover shows the text | |
| Spread out like typing | Spaced as if typed | |

**Q: Cmd+Z in a thread: what happens on the line?**

| Option | Description | Selected |
|--------|-------------|----------|
| Undo is just another edit (Recommended) | Shows like a deletion, with an undo mark | ✓ |
| Undo erases from the line | Undone letters vanish from the line | |

**Notes:** Kaelen added: "we should have a way to delete notes and folders so as not to get too large file sizes with things that don't matter". Deferred, because it conflicts with the append-only journal.

**Q: When not writing, how does a thread look on the 2D canvas?**

| Option | Description | Selected |
|--------|-------------|----------|
| Note card with a thread tail (Recommended) | Card plus a short strand of recent activity | |
| Normal card with a badge | Looks like any note plus an icon | |

**User's choice:** Free text: "A bridge of notes for different context sessions; each session bridges the note, it's the same central note document, but new notes are placed on the timeline for updates. It is a session log so that you can easily revert and head back to previous document stages, which when you update from an earlier point, it branches the thread so that you can create a new document from that point while preserving the original. But it should be those notes on the timeline, with the line drawing it and connecting them."

**Q: Typer open, typing stopped: what does the line do until the time-out?**

**Q: With true-length gaps, how do you get around a months-long thread?**

| Option | Description | Selected |
|--------|-------------|----------|
| Zoom plus session notes to jump (Recommended) | | |
| Zoom plus a date scrubber | | |
| Zoom and pan only | | |

**User's choice:** Free text: "zoom plus session notes to jump plus a date scrubber; clicking one session note flies you to it, yet the timeline remains as it is. It's like space, huge gaps broken up with small planets, but the gravity is enough to easily be able to navigate between them. We need gravity for different notes of bigger sizes, as well as how close you are to notes hovering over them, as well as being able to sort with a date scrubber on a thin timeline bar along the bottom to drag through any day."
