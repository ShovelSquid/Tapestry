## Pattern Assignments

### `app/src/main/threads/thread-service.ts` (service, event-driven + batch)

**Analog:** `app/src/main/kernel-bridge.ts`

**Class + lifecycle shape** (kernel-bridge.ts:89-144). Copy: a single private handle,
`ensureLoaded()` guard, explicit `close()` that clears in-flight state rather than
relying on GC.
```typescript
export class KernelBridge {
  private instance: any = null
  private openPath: string | null = null
  close(): void { … this.instance = null; this.currentSeq = 0; this.undoStack = [] }
  private ensureLoaded(): void {
    if (!this.instance) throw new Error('No kernel loaded — call create() or open() first')
  }
}
```

**The rewound-world refusal ThreadService must reconcile against** (kernel-bridge.ts:149-166):
```typescript
submit(actorKind: string, actorId: string, message: string, ops: OpObject[]): CommitResult {
  this.ensureLoaded()
  if (this.currentSeq !== (this.instance.getLastSeq() as number)) {
    throw new Error(
      'Cannot commit while history is rewound; redo to the latest change or discard the undo first',
    )
  }
  const result = this.instance.submit(actorKind, actorId, message, ops)
  this.afterCommit(result.seq)
  return result
}
```
Pitfall 2 in RESEARCH: opening the typer must reconcile to latest first, and no step is
marked confirmed-durable until `submit` returns.

**Actor:** do NOT copy `App.tsx:202-204`'s `submit('human', 'local', …)`. That call shape is
replaced by main-side stamping — `bridge.submitAs(getHumanActor(), message, ops)` from
`app/src/main/commands/actor.ts`, created by **02.2 Plan 01**
(`.planning/phases/02.2-obsidian-bridge/02.2-01-PLAN.md:54-55,75-76`). ThreadService must use
that stamped path only; the file does not exist on disk yet.

### `app/src/renderer/threads/use-thread-editor.ts` + `recorder.ts` (hook, event-driven)

**Structure analog:** `app/src/renderer/editor/use-prosemirror.ts`
**Anti-pattern warning:** its body-sync effect (`use-prosemirror.ts:337`,
`tr.replaceWith(0, view.state.doc.content.size, newDoc.content)`) must NOT be carried over —
it fights collab and erases rebased steps.

**Debounce pattern to extend (NOT copy verbatim)** (use-prosemirror.ts:276-289). This is the
D-06 cadence's starting point; ThreadService adds the max-wait because this timer resets on
every keystroke and never fires while typing continuously (Pitfall 1):
```typescript
if (tr.docChanged && !tr.getMeta('externalSync') && !schemaErrorRef.current) {
  onMarkDirtyRef.current(nid)
  if (debounceRef.current) clearTimeout(debounceRef.current)
  debounceRef.current = setTimeout(() => {
    debounceRef.current = null
    onMarkCleanRef.current(nid)
    const newBody = serializeBody(view)
    lastEmittedBodyRef.current = newBody
    onSaveRef.current(nid, newBody)
  }, 300)
}
```

**Unmount flush** (use-prosemirror.ts:292-307) — copy this: a pending debounce at teardown
saves the final body rather than dropping it. The thread equivalent flushes the pending batch
and writes `out`.

**Recorder analog** (`.planning/spikes/004-typer-over-live-thread/typer.js` header, VALIDATED
2026-09-15 at 7–9 ms key→painted median):
> "`dispatchTransaction` inspects `tr.steps`; every step's slice contributes its text, which
> is split into graphemes with `Intl.Segmenter` and placed at the current thread time."

Two constraints the spike proved and the plan must keep:
1. Draw from **transaction steps, not key events**, so typing, paste, undo and IME share one path.
2. Drawing is **independent of the 300 ms save debounce** — glyphs must never wait for a commit.
3. Pair input events **newest-first**, not FIFO (spike trail item 2: FIFO drifted to a 685 ms p95).

**Hour-block time encoding + floating origin** (thread.js:40-43, 623-628):
```javascript
function splitTime(t) { const block = Math.floor(t / BLOCK); return [block, t - block * BLOCK] }
function setOrigin(t) {
  const [block, offset] = splitTime(t)
  uniforms.uOriginBlock.value = block
  uniforms.uOriginOffset.value = offset
  return t
}
```

**Shader prelude** (thread.js:118-135) — `relTime`, `threadPoint`, `unitsPerPx`, `fadeFor`:
```glsl
uniform float uOriginBlock, uOriginOffset, uNowRel, uSpeed, uFade, uFadeOn, uPixelScale, uOrtho;
float relTime(float block, float offset) {
  return (block - uOriginBlock) * 3600.0 + (offset - uOriginOffset);
}
vec4 threadPoint(float rel) { return modelViewMatrix * vec4(0.0, 0.0, -rel * uSpeed, 1.0); }
float unitsPerPx(vec4 mv) { return uOrtho > 0.5 ? uPixelScale : uPixelScale * max(-mv.z, 1e-4); }
float fadeFor(float rel) {
  float age = uNowRel - rel;
  return uFadeOn > 0.5 ? clamp(1.0 - age / uFade, 0.0, 1.0) : 1.0;
}
```
`fadeFor` with `uFadeOn = 1` is exactly D-14 (fade by distance only).

**Upload-range trap — port verbatim** (thread.js:239-258). Without this, history silently
never reaches the GPU:
```javascript
// three uploads only the update ranges when any exist, so a range added after a
// full-upload request would silently replace it. Attributes waiting for a full
// upload take no ranges until the next render has uploaded them.
const pendingFullUpload = new Set()
function markRange(attrs, start, count) {
  for (const a of attrs) {
    if (!pendingFullUpload.has(a)) a.addUpdateRange(start, count)
    a.needsUpdate = true
  }
}
function markAll(attrs) {
  for (const a of attrs) { a.clearUpdateRanges(); a.needsUpdate = true; pendingFullUpload.add(a) }
}
```

**Chunk model** (thread.js:261): sessions are kind 0, gaps kind 1, each at most `CHUNK`
seconds, stored as 4 floats per chunk in `Float32Array`s. D-11/D-13 pauses become a third
kind (kind 2) carrying pause-start time.

**Live vs side camera** (thread.js:632-657) — copy both branches, including the ortho
`uPixelScale = (2 * half) / innerWidth` and `uSideGlyphPx = 14`:
```javascript

  persp.position.set(0.35, 0.28, -1.2); persp.lookAt(0, 0, 6)

  Object.assign(ortho, { left: -half, right: half, top: halfHeight, bottom: -halfHeight })
```
