**[G1] — 02.3-01-T2's D-26 rename gate, and 02.3-01-T1's stylesheet grep.** Markdown table cells escape `|` as `\|`, and a copied `\|` is a *literal pipe* in ERE — which silently breaks the alternation so the gate matches nothing and passes vacuously. Both commands are therefore given here unescaped, in fenced blocks, and these are the forms to copy. They match `02.3-01-PLAN.md:155` and `:113`:

```bash
# 02.3-01-T2 — no old vocabulary remains (ERE: bare | alternation)
! grep -rn -iE 'thread-center|thread-arm|threadcenter|THREAD_CENTER' app/src plugins sdk
```

```bash
# 02.3-01-T1 — the renamed stylesheet classes exist (BRE: backslash-pipe alternation)
grep -n 'knot-node\|knot-editor' app/src/renderer/App.css
```

Note the two are deliberately different: the first is `grep -E` where alternation is a bare `|`, the second is plain `grep` (BRE) where alternation *is* `\|`. Copy each exactly as fenced above.

**[G2] — the D-27 camera guard, both views.** Beyond the positive `parseThreadFrame` grep in the row above, Plan 04 Task 2 and Plan 07 Task 1 each carry the *identical* negated literal-triple guard, so neither view can ship a camera basis the other would reject. `roll` lives on the up vector and the eye is a position, so `up.set(...)` and `position.set(...)` are real escapes alongside `lookAt`:

```bash
! grep -nE '(lookAt|(position|up)\.set)\( *-?[0-9.]+ *, *-?[0-9.]+ *, *-?[0-9.]+' app/src/renderer/threads/stage/live-view.ts
! grep -nE '(lookAt|(position|up)\.set)\( *-?[0-9.]+ *, *-?[0-9.]+ *, *-?[0-9.]+' app/src/renderer/threads/stage/side-view.ts
```

This is a backstop, not a proof: it can match a legitimate non-camera literal placement, and it misses `camera.lookAt(new THREE.Vector3(0,0,-1))`. A genuine non-camera match is restructured so the guard passes honestly — never suppressed.

**[B1] — why every bench call goes through an npm script.** `npm --prefix app exec` does **not** change directory: measured in this checkout it stays at `/Users/kaelencook/Tapestry`, so a bare `electron test/bench/thread-bench.cjs` cannot find the harness, which lives at `app/test/bench/thread-bench.cjs`. (`npm --prefix app run` *does* chdir to `app/`, and finds the hoisted `electron` at the repo root's `node_modules/.bin`.) Plan 04 Task 1 now defines a `bench` script in `app/package.json`, and 02.3-04-T2 and 02.3-07-T1 call it as `npm --prefix app run bench -- --bench` / `-- --shots`. **RESOLVED 2026-09-15:** `02.3-05-PLAN.md` and `02.3-08-PLAN.md` were outside that revision's write scope and carried the unresolvable `npm --prefix app exec` form; the orchestrator corrected both to `npm --prefix app run bench -- --shots`. Every bench and shots call site in this phase now goes through the `bench` script Plan 04 Task 1 defines, and the rows above are quoted as the plans actually run them.
