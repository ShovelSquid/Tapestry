- **Quote-anchor resolution (`insert_into_thread`'s `after`, `replace_in_thread`/`delete_from_thread`'s `quote`) cannot match across a paragraph break.** `thread-tools.ts`'s `flatTextOf` walks only text-node characters (no synthetic separator at a block boundary), matching the tracer's own current document model; an agent's quote must stay within one paragraph's own text. Widening this is bounded to `thread-service.ts`'s `flatTextOf` should a later plan need it.

None of the above are placeholder UI shown to a user as if it were real data; each is either an honestly-scoped simplification with a documented reopening seam, or explicitly deferred work whose root cause (no live steps broadcast) is named once and referenced from every affected stub above.
