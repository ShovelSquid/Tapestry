# Phase 02 — UI Design Contract

> Visual and interaction contract for the plugin host, SDK, and feasibility gate. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (toolkit undecided -- Phase 2 feasibility gate determines it) |
| Icon library | not selected (toolkit-dependent; Lucide recommended for web candidate) |
| Font | System font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif` |

The UI toolkit is explicitly undecided (CLAUDE.md, STACK.md). Phase 2 settles it through the feasibility gate. The preferred candidate is C++20 executable + Electron web UI + TS/JS SDK. This contract specifies toolkit-independent visual values (sizes, weights, colors, spacing) that apply regardless of the toolkit outcome. Implementation translates these values into the chosen toolkit's units and APIs.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within bubbly controls |
| sm | 8px | Compact element spacing, control internal padding, note text-to-border gap |
| md | 16px | Default element spacing, note card padding, toolbar group gaps |
| lg | 24px | Section padding, gap between inspector groups, note minimum margin on canvas |
| xl | 32px | Layout gaps between major UI regions (tool strip to canvas edge) |
| 2xl | 48px | Empty state text offset from canvas center |
| 3xl | 64px | Reserved; unlikely in canvas-primary UI |

Exceptions: Bubbly control hit targets: 44px diameter minimum (touch-friendly, D-06). Tool strip items: 36px minimum dimension. Formatting toolbar items: 32px minimum dimension. Thread center node minimum size: 44px when empty (must be a reliable click target, D-18).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 13px | 400 (regular) | 1.4 |
| Heading | 22px | 600 (semibold) | 1.25 |

Two weights only: 400 (regular) for body text and labels, 600 (semibold) for headings and emphasis. Labels are distinguished from body text by their smaller 13px size rather than by weight.

These roles apply to application chrome and default note content. User-authored rich text (D-23) uses Body as the default and Heading for user-applied heading formatting. Bold formatting within notes uses weight 600 on body text. Italic uses the corresponding italic/oblique style. Font family selection (D-23) is a user content feature handled by the editor plugin; the system font stack above governs UI chrome only.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #F7F5F0 | Canvas background, application surface |
| Secondary (30%) | #FFFFFF | Note card surface, toolbar backgrounds, panel backgrounds |
| Accent (10%) | #4A7CFF | Connection handles, selection rings, active passage brackets, thread highlight lines |
| Destructive | #E5484D | Delete bubble (D-06), error indicators, save-failure state |

Accent reserved for: connection handle bubbles (D-06), selected-note focus ring (D-08), active/selected passage bracket outlines (D-13), hovered/selected thread lines, save-error indicator color, toolbar active-tool indicator, link/follow affordances.

### Passage and thread visual guidance (D-13, D-14)

These values implement the gradient-of-focus hierarchy the user described. All passage highlights use the accent hue (#4A7CFF) at varying opacity:

| State | Background opacity | Bracket visibility |
|-------|-------------------|--------------------|
| Linked passage, not hovered/selected | 8% | Hidden |
| Active passage (smallest at pointer) | 25% | Visible, accent at 60% opacity |
| Enclosing passage (one level out) | 15% | Visible, accent at 40% opacity |
| Enclosing passage (two+ levels out) | 10% | Visible, accent at 30% opacity |
| Thread line, default | N/A — use #B0ADA6 (warm gray) at 100% | N/A |
| Thread line, hovered/selected | N/A — use accent #4A7CFF at 100% | N/A |

Shorter passages receive stronger emphasis in partial overlaps (D-14). Equal-length tie behavior is unresolved (CONTEXT.md acknowledges this); implementation should use document order as tiebreaker (earlier passage wins).

### Note and control visual guidance (D-06, D-08)

| Element | Default | Hovered/selected |
|---------|---------|-----------------|
| Note card border | #E0DDD7 (warm gray, 1px) | Accent #4A7CFF (2px) |
| Note card shadow | 0 2px 4px rgba(0,0,0,0.06) | 0 2px 8px rgba(0,0,0,0.10) |
| Connection handle bubble | Accent #4A7CFF, 28px diameter | Scale to 32px on hover |
| Delete bubble | Destructive #E5484D, 28px diameter | Scale to 32px on hover |
| Thread center node (empty) | Secondary #FFFFFF, 1px #E0DDD7 border, 44px min | Accent border on hover |
| Thread center node (has text) | Secondary #FFFFFF, same as note card | Same as note card |

Bubbly controls use rounded/circular shapes with complementary icon glyphs inside. Controls appear on note hover or selection and remain reachable while the pointer moves from the note to its controls (D-06). The connection handle and delete bubble are the two mandatory controls; additional controls may be added with distinct hues that maintain sufficient contrast against both dominant (#F7F5F0) and secondary (#FFFFFF) backgrounds.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Note" (tool strip label; primary creation is double-click canvas per D-04) |
| Empty state heading | "Double-click anywhere to start" |
| Empty state body | "Create notes, connect ideas, and build your world of thought." |
| Error state (file open) | "Could not open [filename] -- The file may be damaged or in an unrecognized format. Create a new world or choose another file." |
| Error state (plugin crash, initial) | "[Plugin name] stopped working. Restarting..." (D-34) |
| Error state (plugin crash, restart failed) | "[Plugin name] could not restart. Your work is safe." Actions: **Restart** / **Dismiss** (D-34) |
| Destructive action | Delete Note: No confirmation dialog. Undo restores deleted notes, passage anchors, threads, and connections together (D-22). Red delete bubble and keyboard Delete on whole-note selection are the triggers (D-21). |

### Save state indicator copy (D-02, beside file name)

| State | Indicator |
|-------|-----------|
| All changes saved | "Saved" (Label role: 13px/400, neutral color) |
| Save in progress | "Saving..." (Label role: 13px/400, neutral color) |
| Save failed | "Not saved" (Label role: 13px/400, destructive color #E5484D) |

The indicator sits beside the file/project name in the top-left corner (D-05). Never imply unsaved text was saved (D-02). The exact debounce timing is an implementation detail; the visual contract is that the indicator reflects ground truth at all times.

### Tool strip labels (D-05)

| Tool | Label |
|------|-------|
| Selection tool | "Select" |
| Note creation tool | "Note" |
| Connection tool | "Connect" |
| Drawing tool | "Draw" |

Tool strip uses icon-primary design with labels visible on hover or in an expanded state. Exact strip position (bottom or floating) follows the brief's suggestion and is resolved during implementation.

| overflow | Formatting toolbar (nav) | covered | D-24/D-25: expandable hierarchy with hover-to-reveal submenus; collapse after short delay on leave |

| long-text | Note text editor (form) | backstop | Note card expands vertically as text grows; user can resize width (D-08); text reflows while passage anchors survive (D-11) |
| long-text | Save state indicator (static-content) | backstop | Filename truncated with ellipsis at max display width of 200px; full name in hover tooltip |
