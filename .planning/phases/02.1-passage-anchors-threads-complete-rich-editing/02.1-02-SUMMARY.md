### Architecture

- Passage plugin uses `handleDOMEvents` to track mouse position in the editor
- At each cursor position, finds all passage marks at that offset
- Sorts by span length (smallest first = strongest highlight)
- Renders ProseMirror decorations with CSS opacity classes: `.passage-focus-1` (25%), `.passage-focus-2` (15%), `.passage-focus-3` (10%), default (8%)
- PassageChooser renders as a fixed-position popup sorted by span length
