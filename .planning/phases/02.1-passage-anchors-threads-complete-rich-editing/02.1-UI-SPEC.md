# Phase 02.1 — UI Design Contract

> Visual and interaction contract for passage anchors, thread center nodes, gradient-of-focus hover hierarchy, and complete formatting toolbar with universal editing. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Inherits and extends the Phase 02 UI-SPEC visual foundation.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (custom React + CSS components; ProseMirror for text editing) |
| Icon library | Inline SVG glyphs (established Phase 2 pattern; no external icon library) |
| Font | System font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif` |

This phase continues the toolkit established in Phase 2: Electron + React + ProseMirror + plain CSS. No component library or design system framework is used. All UI elements are custom components with CSS classes following the `tapestry-` prefix convention.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within toolbar buttons, bracket indicator thickness |
| sm | 8px | Toolbar group gaps, submenu item padding, passage chooser item padding |
| md | 16px | Note card padding (existing), floating toolbar offset from selection, thread center node padding |
| lg | 24px | Gap between toolbar and submenu panels |
| xl | 32px | Formatting toolbar minimum offset from canvas edges |
| 2xl | 48px | Reserved |
| 3xl | 64px | Reserved |

Exceptions: Toolbar button hit targets: 32px x 32px (D-24 formatting items). Thread center node empty state: 44px minimum dimension (touch-friendly click target, D-18). Connection handle bubbles: 28px diameter, scaling to 32px on hover (D-06, carried from Phase 2). Passage bracket visual thickness: 2px (must remain visible at small passage sizes). Toolbar submenu collapse delay: 300ms after pointer leaves (D-25).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Note Title | 18px | 600 (semibold) | 1.25 |
| Label | 13px | 400 (regular) | 1.4 |
| Heading | 22px | 600 (semibold) | 1.25 |

Two weights only: 400 (regular) for body text, labels, and toolbar items; 600 (semibold) for headings, note titles, and bold formatting.

Phase 2.1 typography specifics:

- **Toolbar button labels:** Label role (13px/400/1.4), used for text labels beneath or beside icons when visible.
- **Toolbar submenu item text:** Label role (13px/400/1.4), used for font family names, color labels, heading level names.
- **Thread center node text:** Body role (16px/400/1.5), identical to note body text per D-26 (universal editing).
- **Passage chooser item text:** Label role (13px/400/1.4).
- **Connection status hint text:** Label role (13px/400/1.4), accent or neutral color.
- **User-applied rich text headings (D-23):** H1 = Heading role (22px/600/1.25), H2 = Note Title role (18px/600/1.3), H3 = Body role (16px/600/1.4). These are user content, not chrome.

### Passage and thread visual hierarchy (D-13, D-14)

All passage highlights use the accent hue (#4A7CFF) at varying opacity to implement the gradient-of-focus hierarchy:

| State | Background | Border/Bracket | Text color |
|-------|-----------|----------------|------------|
| Linked passage, idle (not hovered/selected) | rgba(74, 124, 255, 0.08) | Hidden | Unchanged |
| Active passage (smallest at pointer) | rgba(74, 124, 255, 0.25) | 2px left bracket, accent at 80% opacity | Unchanged |
| Enclosing passage, level 1 (one out from active) | rgba(74, 124, 255, 0.15) | 2px left bracket, accent at 50% opacity | Unchanged |
| Enclosing passage, level 2+ (two+ out from active) | rgba(74, 124, 255, 0.10) | 2px left bracket, accent at 30% opacity | Unchanged |
| Pending source passage (held for connection) | rgba(74, 124, 255, 0.30) | 2px bracket, accent at 100% opacity, pulsing | Unchanged |

Passage bracket rendering: a 2px-wide vertical bar on the left edge of the passage span, extending the full height of the passage text. For multi-line passages, the bracket spans all lines. Brackets are only visible when the passage or its thread is hovered/selected (D-13), or when the passage is the pending source of a connection.

Shorter passages receive stronger emphasis in partial overlaps (D-14). Equal-length tie behavior: earlier passage in document order receives the stronger highlight.

The text color picker offers a curated 8-color palette arranged in a 4x2 grid within a submenu. Each swatch is a 24px circle with a 1px border at 10% opacity of the swatch color. The active color shows a 2px accent ring.

| Charcoal (default) | #2C2C2C | 14.7:1 |
| Gray | #6B6B6B | 5.7:1 |

| Blue | #006ADC | 4.8:1 |
| Purple | #6E56CF | 4.5:1 |

|----------|------------|--------|---------------------|

| empty | Passage chooser (nav) | covered | Chooser not rendered when clicked text belongs to zero or one passage; only appears for overlapping passages |
| populated | Passage anchors (list-collection) | covered | D-13/D-14: idle passages get 8% accent background tint; gradient-of-focus hierarchy on hover applies progressively weaker highlights (see Color) |
| populated | Thread connections (list-collection) | covered | Thread lines connect endpoints through center nodes in warm gray; center nodes auto-position at midpoint (D-17) |
| populated | Formatting toolbar with selection (nav) | covered | Toolbar floats above selection bounding box, centered horizontally; all formatting buttons visible in primary row |
| populated | Thread center node with text (form) | covered | Node expands to fit text, rounded rectangle shape, full note editing capability per D-26 |
| populated | Passage chooser (nav) | covered | Clicking overlapping linked text shows chooser listing passage labels/destinations with accent indicator on current highlight |
| overflow | Formatting toolbar submenus (nav) | covered | D-24/D-25: submenu panels expand below toolbar buttons; pointer can move between toolbar and submenu within 300ms grace period |
| overflow | Many overlapping passages (list-collection) | covered | D-14 gradient system scales to arbitrary nesting depth by reducing opacity per level; bracket thickness remains constant at 2px |
| overflow | Many threads from one note (list-collection) | covered | Each thread renders its own line and center node; lines radiate from note edges; center nodes at individual midpoints |
| zero-one-many | Passage anchors per note (list-collection) | covered | Zero passages: clean text; one passage: subtle tint; many passages: layered tints with gradient hierarchy |
| zero-one-many | Threads per note (list-collection) | covered | Zero: no lines; one: single line with center node; many: multiple lines with individual center nodes |

## Interaction Contracts

> Phase 2.1 introduces several new interaction patterns not present in Phase 2. These prescriptive contracts complement the visual specifications above and ensure executor implementation matches the design intent.

### Formatting toolbar positioning and lifecycle (D-24, D-25)

| Trigger | Toolbar behavior |
|---------|-----------------|
| Text selection created in editing note | Toolbar appears centered above selection bounding box, 16px gap above selection |
| Cursor positioned in editing note (no selection) | Toolbar appears above the cursor line, centered on cursor horizontal position |
| Selection extends while toolbar visible | Toolbar repositions to stay centered above new selection bounds |
| Pointer enters toolbar | Toolbar stays open indefinitely |
| Pointer leaves toolbar and selection | 300ms delay, then toolbar hides |
| Pointer leaves toolbar but returns within 300ms | Toolbar stays open (D-25: remain reachable) |
| Submenu button hovered | Submenu panel appears below the triggering button, 4px gap |
| Pointer moves from toolbar to submenu | Submenu stays open (continuous hover region, D-25) |
| Pointer leaves submenu | 300ms delay, then submenu collapses; toolbar remains if pointer is inside it |
| Note loses editing focus (click outside, Escape) | Toolbar hides immediately |
| Formatting button clicked | Formatting applied/toggled; text selection preserved (D-24); toolbar remains visible |
| Scroll or pan while toolbar visible | Toolbar repositions to follow selection in viewport |

### Toolbar button layout (left to right)

| Group | Buttons | Separator after |
|-------|---------|----------------|
| Inline marks | Bold, Italic | Yes |
| Block type | Heading (expandable) | Yes |
| Lists | List (expandable) | Yes |
| Appearance | Text Color (expandable), Font (expandable) | Yes |
| Alignment | Alignment (expandable) | No |

### Passage anchor creation flow (D-09, D-10)

**Flow A: Passage-to-note (select source, click destination connect)**

| Step | User action | Visual feedback |
|------|-------------|-----------------|
| 1 | Select text in source note | Text highlighted with browser selection; formatting toolbar appears |
| 2 | Hover destination note (while maintaining selection) | Destination note shows connect-target ring (existing Phase 2 behavior) |
| 3 | Click destination note's connection handle | Connection created: source passage bracket appears on source text, thread line and center node appear between notes |

**Flow B: Passage-to-passage (hold source, select destination)**

| Step | User action | Visual feedback |
|------|-------------|-----------------|
| 1 | Select text in source note | Text highlighted with browser selection |
| 2 | Click source note's connection handle | Source passage "held": persistent accent bracket with pulsing animation, status hint appears (see Copywriting: pending passage source indicator) |
| 3 | Click in destination note to begin editing | Destination note enters editing mode |
| 4 | Select text in destination note | Destination text highlighted with browser selection |
| 5 | Click destination note's connection handle | Connection created: both passage brackets appear, thread line and center node connect the two passages |

**Flow C: Note-to-note drag (existing Phase 2 behavior, unchanged)**

Drag from connection handle to another note creates a whole-note-to-whole-note connection.

**Escape cancellation:** At any point during Flow A or B, pressing Escape cancels the pending connection, removes the held-source state, and restores normal text selection behavior. Escape does not discard existing text (D-10).

### Passage hover and gradient-of-focus behavior (D-14)

| Pointer position | Visual result |
|-----------------|---------------|
| Over non-linked text | No passage highlights active |
| Over text in exactly one passage | That passage gets active highlight (25% accent bg, bracket visible at 80%) |
| Over text in nested passages (2+ deep) | Smallest passage = active (25%); next enclosing = level 1 (15%); outer = level 2+ (10%); each bracket visible at decreasing opacity |
| Over text in partially overlapping passages | Shorter passage gets stronger emphasis; longer passage gets weaker emphasis; non-overlapping portions of each passage highlight at their own level |
| Pointer moves to different passage region | Previous highlights fade, new gradient-of-focus hierarchy applies immediately (no transition animation) |

### Thread center node positioning (D-17)

| Condition | Position |
|-----------|----------|
| Auto-positioned (default, not yet dragged) | Midpoint of the straight line between the two endpoint nodes/passages |
| User has dragged the center node | User's chosen position persists; no auto-repositioning |
| Endpoint moved (while center is auto-positioned) | Center node follows, maintaining midpoint |
| Endpoint moved (while center is user-positioned) | Center node stays at user's position |

### Passage chooser behavior (D-15)

| Trigger | Behavior |
|---------|----------|
| Click on text belonging to 2+ passages | Chooser popup appears near click position |
| Chooser item clicked | That passage and its thread are highlighted/followed |
| Click outside chooser | Chooser dismisses |
| Escape while chooser open | Chooser dismisses, caret placed at click position |

Chooser is a small floating panel (same visual treatment as formatting toolbar) listing passage entries. Each entry shows the destination note title or a truncated passage preview (max 30 characters with ellipsis). The active/highlighted passage gets an accent left-border indicator (2px, #4A7CFF).
