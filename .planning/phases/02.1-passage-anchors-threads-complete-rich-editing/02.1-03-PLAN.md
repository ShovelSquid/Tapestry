  <action>
    Create app/src/renderer/editor/toolbar-commands.ts. Import tapestrySchema from schema.ts. Import toggleMark and setBlockType from prosemirror-commands. Import wrapInList, liftListItem, splitListItem from prosemirror-schema-list. Export the following command helper functions, each accepting an EditorView and dispatching the appropriate transaction:

    toggleBold(view): toggleMark on tapestrySchema.marks.strong.
    toggleItalic(view): toggleMark on tapestrySchema.marks.em.
    setHeading(view, level): if the current block is already a heading at this level, setBlockType to paragraph; otherwise setBlockType to heading with attrs level. Level is 1, 2, or 3.
    setNormalText(view): setBlockType to paragraph.
    toggleBulletList(view): if the current block is inside a bulletList, liftListItem on listItem; otherwise wrapInList on bulletList.
    toggleOrderedList(view): same pattern with orderedList.
    setTextColor(view, color): apply textColor mark with attrs color to the current selection. If the selection is empty (cursor), set storedMarks. If color is #2C2C2C (default), remove the textColor mark instead.
    setFontFamily(view, family): apply fontFamily mark with attrs family. If family is empty string (System default), remove the fontFamily mark.
    setAlignment(view, align): set the align attr on the current paragraph or heading node. If align is "left" or null, remove the attr (left is default). Accept "left", "center", "right".

    Export an isMarkActive helper that checks whether a given mark type is active in the current selection (for toggling button states). Export an isBlockType helper that checks the current block type and level.

    Create app/src/renderer/components/FloatingToolbar.tsx. This is a React component accepting props: view (EditorView or null), canvasView (panX, panY, zoom for repositioning), onFormatApplied callback (optional, for refreshing toolbar state). When view is null, render nothing.

    Toolbar positioning: use view.coordsAtPos(selection.from) and view.coordsAtPos(selection.to, -1) to get the bounding box of the selection in viewport coordinates. Center the toolbar horizontally above the selection, 16px (md spacing) above the top of the selection. If the toolbar would extend above the viewport, flip to below the selection. Clamp horizontally to stay within viewport with 32px (xl spacing) margin from edges. Recompute position when canvasView changes (pan/zoom), when the selection changes, and on window resize. Store the computed position in state and update via useEffect.

    Toolbar layout (left to right, per UI-SPEC Interaction Contracts): Group 1: Bold button, Italic button, vertical separator. Group 2: Heading button (expandable submenu), vertical separator. Group 3: List button (expandable submenu), vertical separator. Group 4: Text Color button (expandable submenu), Font button (expandable submenu), vertical separator. Group 5: Alignment button (expandable submenu).

    Each button: 32px by 32px, 4px border-radius, transparent background by default, #F7F5F0 on hover, rgba(74, 124, 255, 0.10) when toggled/active. Icon is a 16px inline SVG glyph in #2C2C2C (default) or #4A7CFF (active). Draw simple recognizable SVG icons for each: B for bold, I for italic, H with small level indicator for heading, a three-line icon for list, a filled circle for color (filled with current color), A with font indicator for font, alignment bars for alignment. Use the tooltip text from UI-SPEC (Bold, Italic, Heading, List, Text color, Font, Alignment).

    Vertical separators: 1px solid #E0DDD7, 20px height, between groups.

    Submenu behavior (D-25): track which submenu is open via openSubmenu state (null, or button id). On button hover (mouseenter), if the button has a submenu, set openSubmenu after 0ms (instant open). When the pointer leaves the toolbar AND the submenu, start a 300ms timer. If the pointer re-enters the toolbar or submenu within 300ms, cancel the timer. If the timer fires, set openSubmenu to null. Use a single timer ref. The toolbar and its submenu form a continuous hover region: pointer moving from the toolbar to the submenu (4px gap per UI-SPEC) must not trigger collapse. Implement by wrapping the toolbar + submenu in a container that tracks pointer enter/leave on the whole region, OR by using the 300ms delay to bridge the gap.

    Submenu panels: position directly below the triggering button with 4px gap. Same visual treatment: white background, 1px #E0DDD7 border, 8px border-radius, box-shadow.

    Heading submenu: 4 items -- "Heading 1", "Heading 2", "Heading 3", "Normal text". Each 32px height, 8px 12px padding. Clicking calls setHeading or setNormalText via toolbar-commands.

    List submenu: 2 items -- "Bulleted list" with a bullet icon, "Numbered list" with a number icon. Clicking calls toggleBulletList or toggleOrderedList.

    Text Color submenu: a 4x2 grid of 24px circle color swatches. Colors from UI-SPEC: Charcoal #2C2C2C, Gray #6B6B6B, Red #D13415, Orange #AD5700, Green #18794E, Blue #006ADC, Purple #6E56CF, Magenta #CD2B74. Each swatch has a 1px border at 10% opacity of its color. The active color (matching the current textColor mark in the selection) shows a 2px accent ring. Clicking calls setTextColor.

    Font submenu: 3 items -- "System" (rendered in system font stack), "Serif" (rendered in Georgia), "Mono" (rendered in SF Mono/Menlo). Each item renders its label in its own typeface for preview. The active font shows a checkmark or accent indicator. Clicking calls setFontFamily.

    Alignment submenu: 3 items -- "Align left" with left-align icon, "Center" with center icon, "Align right" with right-align icon. Active alignment shows accent color. Clicking calls setAlignment.

    Formatting interaction (D-24): clicking any formatting button applies/toggles the format and preserves the text selection. After applying, the button state updates to reflect the new format state. The toolbar remains visible after formatting.

    Toolbar lifecycle: the toolbar appears when any ProseMirror editor has focus and either has a text selection or a cursor position. It hides when: the editor loses focus (click outside, Escape), OR 300ms after the pointer leaves both the toolbar and the editor (if no selection exists). It does NOT hide on pointer leave if there is still an active text selection in the editor.

    Add CSS to App.css for the toolbar: tapestry-floating-toolbar class with position fixed (positioned in viewport coordinates), z-index 1000, white background, 1px #E0DDD7 border, 8px border-radius, box-shadow, 4px padding, display flex, align-items center, gap 0. tapestry-toolbar-btn class for each button. tapestry-toolbar-btn--active for toggled state. tapestry-toolbar-separator for the vertical divider. tapestry-toolbar-submenu for submenu panels. tapestry-color-swatch for color circles. tapestry-color-swatch--active for the accent ring. tapestry-font-item for font submenu items. tapestry-align-item for alignment items.
