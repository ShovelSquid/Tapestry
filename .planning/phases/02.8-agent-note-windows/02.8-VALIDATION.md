## Sampling Rate

- **After every task commit:** Run the task's own `<automated>` command (each is a subset of the quick run plus typecheck)
- **After every plan wave:** Run the full suite command
- **Before `/gsd-verify-work`:** Full suite must be green, plus the configured `test_command` (kernel ctest + typecheck), which 02.8-07 Task 2 runs
- **Max feedback latency:** 60 seconds for a task's own command
