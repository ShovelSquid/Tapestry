- the phase gate.

Recorded choices:
- **Turn geometry is measured in layout pixels** (`offsetTop` and `offsetHeight` within the transcript, and the transcript's `scrollTop`, `offsetTop` and `clientHeight`), which canvas transforms do not change. It is published per card, keyed `${treeId}:${noteId}`, on scroll (throttled with requestAnimationFrame), on resize (ResizeObserver) and when the turns change. It is never stored.
- **The line path goes in TreeFrame's existing connections SVG.** The dot is an HTML button in the frame content layer, because the SVG has `pointer-events: none`.
- **An unmeasured original** (not yet drawn) anchors at its bottom edge, like a closed card, until its geometry arrives.
</objective>

  <behavior>
    - anchorY: turn k visible → y = transcriptTop + (turn.top − scrollTop) + turn.height / 2, clamped false; turn scrolled above → y = 8, clamped 'top'; below → y = cardHeight − 8, clamped 'bottom'; closed card or unmeasured geometry → y = cardHeight, clamped 'bottom'
    - anchorSide: fork centre to the right of the original's centre → 'right'; to the left → 'left'
    - nearestEdgeMidpoint(rect, point) returns the midpoint of the rect's edge nearest the point (left, right, top or bottom)
    - forkLine: the start is on the original's facing side at anchorY; the end is the fork's nearest edge midpoint to that start
    - A fork of a fork: two edges give two lines, each with its own turn and original
    - turn-geometry: publishing an equal geometry does not notify listeners; a new one does; requestScrollToTurn(key, 2) is seen once by useScrollToTurnRequest's consumer
  </behavior>

**`layout/fork-anchor.ts` (new, pure).**
- `ANCHOR_INSET = 8`.
- `CardTurnGeometry = { closed: boolean; transcriptTop: number; transcriptHeight: number; scrollTop: number; turns: ReadonlyMap<number, { top: number; height: number }> }`.
- `anchorY(geometry | null, k, cardHeight): { y: number; clamped: 'top' | 'bottom' | null }`.
- `anchorSide(originalRect, forkRect)`, `nearestEdgeMidpoint(rect, point)` and `forkLine(originalRect, forkRect, anchor)`, which returns `{ x1, y1, x2, y2, side }`.
- All values are in frame-local units: card-relative y added to the card's local top.

**`state/turn-geometry.ts` (new).** A module store keyed `${treeId}:${noteId}` with `publishTurnGeometry(key, geometry)` (equal geometry does not notify), `useTurnGeometries(keys)` (one subscription returning a Map, so TreeFrame calls it once for all its fork edges rather than in a loop), `requestScrollToTurn(key, k)` and `useScrollToTurnRequest(key)` (a nonce pattern, consumed once).

**Transcript and card.** The card passes `closed` and its key. The transcript publishes geometry from each turn group's `offsetTop` and `offsetHeight`, its own `offsetTop` within the card, `clientHeight` and `scrollTop`: on scroll (rAF-throttled), through a ResizeObserver, and when the committed turns change. It also consumes scroll-to-turn requests by setting `scrollTop` to put turn k near the top, with no flash.

**`ForkedFromLine.tsx` (new).**
- `ForkedFromPath({ x1, y1, x2, y2 })` renders one SVG `<line>`: stroke `var(--tap-thread-line)`, width 1.5, round caps.
- `ForkAnchorDot` is added to this file in Task 2.

**TreeFrame.tsx.** In the connections SVG, an edge whose label is `FORKED_FROM_LABEL`, with a session node at both ends, is drawn as `ForkedFromPath`:
- the original is `edge.to` and the fork `edge.from`;
- the rects are the drawn local positions plus `getDims` (falling back to the stored `width`/`height`);
- the anchor is `anchorY(geometries.get(originalKey) ?? null, edge.props.turn value, originalHeight)`, where `geometries` comes from one `useTurnGeometries` call at the top of TreeFrame.

Every other edge keeps `ConnectionLine`.
