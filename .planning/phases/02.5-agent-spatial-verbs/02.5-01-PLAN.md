<objective>
**As an** agent working in a Tapestry tree, **I want to** ask which notes sit around a note and how they relate to it, **so that** I can decide where my notes should go without ever being handed coordinates.

This plan builds the environment the phase needs (Wave 0), then ships `look` end to end as the phase's tracer: an MCP call travels through the shim, the strict schema, the dispatch switch and a new `SpatialCommands` class, reads the world through the new pure module `app/src/renderer/layout/placement.ts`, and returns relations only (D-14). Purpose: prove the one architectural risk early — main importing a pure module from the renderer's layout folder with no tsconfig change (D-18) — and give agents a working sense of sight before any write verb exists.

Output: `placement.ts` and its tests, `spatial.ts` and its tests, the `look` tool (nine tools in total), and a green baseline recorded in the SUMMARY.

This plan does **not** depend on Phase 2.4.
</objective>
