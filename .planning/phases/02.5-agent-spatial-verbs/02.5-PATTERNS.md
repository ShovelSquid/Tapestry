## Can main import `src/renderer/layout/`? Yes (verified)

- `app/tsconfig.node.json` has `"rootDir": ".."`, `"include": ["src/main/**/*", "src/preload/**/*"]`, and `lib: ["ES2020"]` (no DOM). A file that main imports is pulled into the program even though it is not in `include`, and because `rootDir` is `..`, it passes the TS6059 check.
- **Probe run:** a scratch tsconfig that extends `app/tsconfig.node.json` (only `rootDir` and `typeRoots` changed, so the probe file outside the repo could load) and imports `app/src/renderer/layout/frames` typechecked with **exit 0**. No repo file was touched.
- `app/tsconfig.web.json` (`rootDir: "src/renderer"`, include `src/renderer/**/*`) already covers `placement.ts`.
- `app/electron.vite.config.ts`: the `main` build is a normal Rollup bundle with inputs `src/main/index.ts` and `src/main/mcp/shim.ts`. `externalizeDepsPlugin` externalizes only packages, and `external` covers only `/\.node$/`. A relative import of `../../renderer/layout/placement` is simply inlined into `out/main/index.js`. Nothing blocks it.
- **Caveat:** `app/src/main/index.ts:392-401` says main *repeats* `FRAME_MIN_WIDTH`/`FRAME_GAP` "rather than imported because main and renderer are separate bundles". That was a style choice, not a build limit. This phase is the first main→renderer import, so note it in the module header.
- **Constraints on `placement.ts` that follow from this:**
  1. It imports nothing. `frames.ts` is the model: zero imports.
  2. No DOM types or globals, since the node config has no `DOM` lib. Also no `process` or Node types, since the web config has no `types: ["node"]`.
  3. It declares its own structural node and edge types. It must not import `NodeInfo` from `components/Canvas.tsx`: that is a `.tsx` file, and the node config has no `jsx` setting. It must not import `NodeData` from `main/kernel-bridge.ts` either, because that is outside the web `rootDir`. The shapes are identical, so structural typing lets both sides pass their own types (`Canvas.tsx:39-51`, `kernel-bridge.ts:64-76`).
  4. It must pass the web config's `noUnusedLocals` and `noUnusedParameters` settings.
  5. `mcp/schemas.ts` must NOT import it (shim bundle rule, `schemas.ts:4-7`).

## Shared Patterns

### Refusal = `{ ok: false, error }`, nothing written
**Source:** `app/src/main/commands/notes.ts` (`CommandResult`, `writeToOwnNote` 570-597)
**Apply to:** spatial.ts, the `where` path in notes.ts. Every check before `submitAs` returns a sentence and writes nothing. Checks that do not need world state come before `prepareWriteFor`.

### Actor is never an argument
**Source:** `agent-tools.ts:1-14` header, and every schema is `.strict()`.
**Apply to:** `LookArgs`, `PlaceArgs`, `WhereArgs`, the tool cases.

### Commit via `submitAs` + `onCommitted`
**Source:** notes.ts:310, 322 (`createFrom`)
```ts
const result = bridge.submitAs(actor, `grow note "${title}" from ${args.grewFrom}`, ops)
...
this.hooks.onCommitted?.(tree.id, actor, result)
```
**Apply to:** `place`, with the message `Place note near n7` / `Place note beyond n7 from n4` (D-04).

### Pure geometry, one source of truth
**Source:** `app/src/renderer/layout/frames.ts`. Its header says "agree by construction rather than by two similar-looking expressions staying in step".
**Apply to:** placement.ts, consumed by spatial.ts, notes.ts, Canvas.tsx and TreeFrame.tsx.
