`fences(text)`: line-based from `frontmatter::body_start`. An opener is a line that, after stripping any `>` quote markers (each optionally followed by one space) and up to 3 spaces, starts with 3 or more backticks or 3 or more tildes (a backtick opener's info string must contain no backtick). The closer is a later line with the same quote-stripping whose run is the same character, at least as long as the opener, followed only by whitespace. Unclosed runs to EOF. Ranges cover the opener line start to the closer line end including its line ending.

`mask(text)`: the frontmatter region `0..region.body_start` when split gives Parsed or Invalid with a region; every fence range; then one left-to-right pass over the remaining text that takes whichever starts first: `%%` to the next `%%` (may span lines; unclosed to EOF), `<!--` to the next `-->` (unclosed to EOF), or a backtick run of length n to the next run of exactly n within the same paragraph (a blank line ends the paragraph; an unmatched run is literal and skipped). Return sorted, merged ranges.

`parse(text)`: find each `[[` whose start is outside the mask. The closing `]]` must be on the same line; if another `[[` appears before it, restart from that inner `[[`; if the `]]` falls inside a masked range, there is no link. A preceding `!` makes it an embed and moves the span start to the `!`. Inside: split at the first `|`; when the byte before it is `\`, set escaped_pipe and exclude the `\` from the target part. Split the target part at the first `#`: a subpath starting with `^` is a Block (range excludes `^`), otherwise a Heading (may contain more `#`). Trim ASCII whitespace from target, subpath and alias ranges. Skip links whose target is empty and that have no subpath.

`targets(text)`: target text of each parsed link, trimmed, non-empty, deduplicated by exact string in first-appearance order, embeds included.
