# Phase 02.4 Plan 01: Lock Model Summary

Agents can now change a note unless it is locked against them, and authorship no longer decides. `locks.ts`, a new read-only module, works out whether a note's `text` or `delete` aspect is locked: an explicit `lock.<aspect>` value (which fails closed if malformed) or a default based on who created the note. The default constants are `NON_AGENT_NOTES_DELETE_LOCKED` and `AGENT_NOTES_OPEN_TO_AGENTS`, both `true` and marked PENDING. Update, rename and delete all pass through one gate in `notes.ts`.
