## Default lock set

Why this came up: on main, the Obsidian bridge signs vault notes `plugin obsidian.bridge` (02.2 D-21). A default of "locked if a person wrote it" would therefore leave every vault note open to agents.

| Option | Description | Selected |
|--------|-------------|----------|
| All but agent notes (Recommended) | Any note not created by an agent starts locked: yours, Obsidian notes, and other plugins' notes. Agent notes start open. | ✓ |
| Only notes you wrote | Only notes signed by a person start locked. Obsidian and plugin notes start open to agents. | |

**User's choice:** All but agent notes (the orchestrator, under the grant)
**Notes:** Because the locked set is now wider than "user notes", the pending constant is named `NON_AGENT_NOTES_DELETE_LOCKED` instead of `USER_NOTES_DELETE_LOCKED`.
