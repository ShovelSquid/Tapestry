# Phase 2.4: Lock Model Verification Report

**Phase Goal:** Agents may change any note that is not locked against them. A lock, not authorship, decides who may write. Every note not created by an agent (a person's, an Obsidian vault note, another plugin's) starts with its text and deletion locked. Agent notes start open. An explicit lock on a note can close it, open it, or name who else may write.
