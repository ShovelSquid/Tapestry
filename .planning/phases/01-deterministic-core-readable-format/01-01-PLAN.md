## Phase Goal

> The world's content, relationships, changes, and history live in a durable `.tree` journal a person can read without Tapestry — and unknown plugin data stays readable and safe

**Mode:** mvp (Walking Skeleton — see `01-SKELETON.md`). This plan is the scaffold half of the skeleton: it locks the on-disk format decision, stands up the rendering-independent kernel target and test runner, and delivers the typed value/time/id primitives every record is made of. Plan 02 is the end-to-end tracer.

<format_contract>
The v1 grammar Task 1 asks the user to confirm. Tokens are space-separated; the file is UTF-8 with LF line endings, no BOM, no tabs in structural lines.

```text
@tree 1 <bytes>                        # header record, first bytes of the file; <bytes> = byte count of the body lines
world <slug>                           # human-chosen name, one token, not an id
created <YYYY-MM-DDTHH:MM:SSZ>
@end sha256:<64 lowercase hex>         # SHA-256 over "@tree 1 <bytes>\n" + body, exactly as written

@commit <seq> <bytes>                  # seq = 1,2,3… ; <bytes> = byte count of everything between this line's LF and the "@end" line
parent sha256:<64 hex>                 # digest of the previous record (the @tree record for seq 1)
branch main                            # Phase 1 always "main"
recorded <YYYY-MM-DDTHH:MM:SSZ>        # wall clock at commit, audit only, never ordering
tick <n>                               # world tick at which this commit applies; only "advance" changes it
actor <human|plugin|system> <id>       # id is one token
message "<inline text>"                # optional
create-node n<k> <type>                # type is one token, opaque namespaced string, e.g. tapestry.notes/note@1
set <n<k>|e<k>> <key> <type> <value>   # value types: text | int | real | bool | ref | time
set n1 body text <<TEXT                # multi-line text: delimiter TEXT, TEXT1, TEXT2… first one not equal to any body line
Met Sam at dinner.
Loves architecture and weird bird memes.
TEXT
unset <id> <key>
create-edge e<k> n<a> n<b> <label>
delete-node n<k>
delete-edge e<k>
advance <n>
x-<anything>                           # extension line: preserved verbatim, never interpreted
@end sha256:<64 hex>                   # over "@commit <seq> <bytes>\n" + body
```

Value encodings: `text` inline is a double-quoted string with JSON-style escapes for quote, backslash, LF, tab, CR and `\uXXXX` for other control characters, used when the text has no LF and is at most 80 bytes; otherwise the block form. `int` is a decimal int64. `real` is `std::to_chars` shortest round-trip (`0.1`, `1e+300`, `-0`); NaN/Inf rejected. `bool` is `true`/`false`. `ref` is `n<k>`/`e<k>` and must resolve. `time` is an EDTF Level 0/1 or RFC 3339 string, unquoted. Keys match `[A-Za-z_][A-Za-z0-9_.:-]*`.
</format_contract>

      <pros>Long notes stay literally readable (no escaped newlines); framing by byte count makes embedded `@end` text inert; digest over bytes-as-written needs no canonicalization; no extra library; ids are short and readable; second-precision stamps read cleanly</pros>

    </option>
