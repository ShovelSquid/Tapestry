## Phase Goal

> The world's content, relationships, changes, and history live in a durable `.tree` journal a person can read without Tapestry — and unknown plugin data stays readable and safe

**Mode:** mvp — this plan is the tracer half of the Walking Skeleton (`01-SKELETON.md`): the thinnest production-quality path from `Kernel::submit` through the codec and the durable journal to disk and back.

<objective>
Wire ONE path end-to-end and for keeps: create a node with initial typed properties → validate → encode a `@commit` record → single `write` + `F_FULLFSYNC` through the `Sink` seam → apply to the in-memory `World` → reopen the file in a fresh kernel and read the node back. The header record, digest chain, byte-counted envelope, open-time classification (Ok / TornTail / Corrupt), single-writer lock and rejection-leaves-nothing-changed semantics are all real on this one path; the wider op set, block text, extension lines, failure-injection sweeps and repair are expansion tasks in Plans 03-05.

Purpose: prove the architecture (pure codec, injectable sink, validate → durable write → apply ordering) on the agent's best early context before ten layers are committed on top of it.
Output: `kernel/{Result,Ops,Record,World,Kernel}.hpp`, `kernel/tree/Codec.hpp`, `kernel/journal/{Sink,Journal}.hpp` (Task 1 contracts); `kernel/{World,Kernel}.cpp`, `kernel/tree/{Encoder,Decoder}.cpp`, `kernel/journal/{Sink,Journal}.cpp`, `kernel_tests/kernel_test.cpp` (Task 2 tracer).
</objective>
