## Phase Goal

> The world's content, relationships, changes, and history live in a durable `.tree` journal a person can read without Tapestry — and unknown plugin data stays readable and safe

**Mode:** mvp — expansion slice 1 on the tracer: the full v1 op set, readable multi-line text and the "unknown data stays readable and safe" guarantees (TREE-02).

<objective>
Expand the tracer's single path into the complete v1 op vocabulary and value forms, and prove the extensibility guarantees: unknown node types load as ordinary typed data, `x-` extension lines survive verbatim, unknown op verbs stop the load loudly, ids stay stable and never collide after reopen, and the codec is byte-exact in both directions.

Purpose: TREE-02 is what lets Phase 2 plugins own meaning while the kernel stays small — the kernel must never need to understand a plugin's node type to load, save or display a readable fallback.
Output: extended `kernel/Ops.hpp`, `kernel/World.{hpp,cpp}`, `kernel/tree/{Codec.hpp,Encoder.cpp,Decoder.cpp}`; new `kernel_tests/codec_test.cpp`; extended `kernel_tests/kernel_test.cpp`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-04 | Tampering | kernel/tree/Decoder.cpp UTF-8/NUL validation | medium | mitigate | Every body line and block is validated as UTF-8 with NUL rejected → InvalidUtf8 with offset; inline strings escape controls so a later UI never receives raw control bytes from an inline value (Task 1) |
| T-1-05 | Spoofing | kernel/tree/Encoder.cpp block delimiter | medium | mitigate | Delimiter escalates (TEXT, TEXT1, …) until no body line equals it; framing remains byte-counted so embedded `@end` text is inert; tested with a body line equal to TEXT (Task 1) |
| T-1-02 | Denial of service | kernel/tree/Decoder.cpp limits | medium | mitigate | kMaxRecordBytes checked before allocation, kMaxLineBytes per line, block scan bounded by the counted body (Task 1) |
| T-1-14 | Tampering | kernel/World.cpp id assignment | medium | mitigate | Ids assigned only in prepare, explicit ids must equal the next counter (IdOutOfOrder), tombstones prevent reuse — a crafted file cannot alias two entities to one id (Task 1/2) |
| T-1-15 | Information disclosure | extension lines re-emitted verbatim | low | accept | x- lines are plugin-owned readable data by design; the kernel neither interprets nor filters them; a plugin that writes secrets into them is a Phase 2 capability concern (documented in FORMAT.md) |
</threat_model>
