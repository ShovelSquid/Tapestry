<objective>
Every durable change is signed by the Electron main process, never by the caller. Human edits read `actor human user.<name>` (D-07). Plugins are bound to `actor plugin <pluginId>` and cannot claim `human` or `system`, which is the host-stamping foundation that agent ids rely on (D-06). The shared command layer (D-01) builds on these helpers. A first-run prompt asks for the name, and the Wave 0 test harness (vitest, temp trees, real-data guard) is installed.

Purpose: identity is the riskiest part of this phase (RESEARCH "Key insight"). Closing the actor-spoofing hole first means every later slice (MCP agents, vault observations) inherits honest attribution.
