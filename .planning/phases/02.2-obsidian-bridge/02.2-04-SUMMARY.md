# Phase 02.2 Plan 04: The Full Agent Tool Set and the Agents Panel Summary

**An agent can now read, search, grow, edit, rename, delete and connect notes over MCP — and may change only the notes it created, a rule read from the `actor` line of the commit that created each note rather than from anything the agent could claim about itself.**

## Performance

- **Duration:** 25 min
- **Tasks:** 3
- **Files modified:** 21 (8 created, 13 modified)

## Accomplishments

- **Made ownership a fact rather than a claim.** `assertOwnNote` reads `getHistoryIndex().nodes[note].createdBy` — the actor line of the creating commit — and compares it with the calling actor. There is no created-by property anywhere in the file, so an agent cannot grant itself ownership by writing one. `agent.chatgpt` is refused on `agent.claude`'s note just as firmly as on Kaelen's, which is what makes D-06's "agents are distinguishable" mean something operationally.
- **Checked ownership against the world the commit will land in.** A rewound tree displays an earlier state, so ownership is checked *after* the tree is returned to its head, not before. Checking the rewound view and then appending at the head would have answered a question about a different world.
- **Replaced a refusal with a reconciliation.** Plan 03 refused any commit while history was rewound. That would have meant an agent's work being dropped because Kaelen happened to press undo — so `discardRedo()` returns the tree to its head, the write lands, and `onRedoDiscarded` says the redo is gone (UA-14). Losing redo silently was the failure worth avoiding; losing the agent's note was the worse one.
- **Proved every refusal writes nothing.** Each of the nine refusal paths asserts both `{ok:false}` *and* that file size, node count and edge count are unchanged — and, where it applies, that the note still holds the text its author wrote.
- **Quoted every value in the connect command.** `shellQuote` single-quotes and escapes, so a userData path containing "House Party" stays one argument and a crafted value cannot close the quote and append a command (T-02.2-23) — asserted directly with a hostile input. The token appears exactly once, because only its SHA-256 is stored and the dialog is the single chance to copy it.
- **Made "connected" an observation.** The shim opens one connection per call, so an open socket proves nothing. An agent reads as connected because a request carrying its token arrived within 120 seconds; an unknown token never counts, and the persisted last-connected time survives the idle-out so the panel can still say when it last was.
- **Stopped rewriting the credential file on every call.** `markConnected` is throttled to one write per agent per minute — `agents.json` decides who may write to the world, and a connection time is worth knowing to the minute, not worth rewriting that file for on every tool call.

## Decisions Made

See `key-decisions` in the frontmatter. The two worth repeating:

- **The agents switch is Ink, not accent.** The UI-SPEC reserves the accent for a listed set of elements, and a settings toggle is not one of them, so the "on" state uses `#2C2C2C`.
- **`connect_notes` refuses cross-tree endpoints rather than writing one end.** D-16 requires both trees to record a cross-tree link; writing only the local end now would leave the other tree with no record that the link exists.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A raw NUL byte in `notes.ts` made the file binary to grep**
- **Found during:** Task 1, checking the acceptance criteria
- **Issue:** Plan 03's NUL check was written with a **literal NUL byte** in the source (`raw.includes(<NUL>)`) rather than the `\0` escape. It works correctly, but it makes the whole file binary to BSD grep: `grep -c "may only change notes it created" notes.ts` printed nothing and `grep -q . notes.ts` failed, so **two of this task's four acceptance criteria silently reported no match** while the code was present and its tests passing. Any future grep-based verification of this file would have been just as silently wrong.
- **Fix:** Replaced the raw byte with the `\0` escape (behavior-identical; confirmed that the escape is the same character and that `includes` still detects a NUL). The file is now plain text and both criteria print their expected matches.
- **Files modified:** `app/src/main/commands/notes.ts`
- **Verification:** `grep -c "may only change notes it created"` → 1; `grep -n "discardRedo"` → matches; 103/103 tests pass
- **Committed in:** `7030918` (Task 1 commit)
