# Phase 02.2 — UI Design Contract

> Visual and interaction contract for the agent MCP bridge and the Obsidian vault bridge: several named tree frames in one space, vault folder groups, placeholder and file notes, wikilink and cross-tree connections, readable provenance, per-tree sync state, the lossy-copy prompt, the first-run name prompt, the tree entry points and the agents panel. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Inherits and extends the approved Phase 02 and 02.1 UI-SPECs. No palette, type scale or spacing value from 02.1 is changed.

Generated unattended (`--auto`). No user questions were asked. Every choice that CONTEXT.md, RESEARCH.md, the 02.1 UI-SPEC and the renderer code did not settle is listed in **Assumptions for Review** at the end, each with an id (`UA-nn`) that the sections below cite.

Same four roles and two weights as 02.1. No new size or weight.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|

Phase 2.2 role assignments:

- **Frame name** ("we", "House Party"): Note Title (18/600/1.25), #2C2C2C. When canvas zoom is below 0.72 the frame name counter-scales so it never renders smaller than 13px on screen (DRAW-03, UA-11).
- **Frame kind label** ("Tapestry world", "Obsidian vault") and **frame status text**: Label (13/400/1.4).
- **Folder group label** ("Characters"): Label, #6B6B6B.
- **Vault note title** (= file name without `.md`): Note Title, same input as native notes.
- **Vault note body** (Markdown text verbatim): Body (16/400/1.5), `white-space: pre-wrap`.
- **Placeholder note title** (link text): Note Title, color #6B6B6B. Its hint line: Label.
- **File note name**: Body; type/size line and "Open file": Label.
- **Provenance footer, tag chips, connection label chips, remote stubs, forest bar buttons, menu items, validation messages**: Label.
- **Dialog title**: Heading (22/600/1.25). **Dialog body and field text**: Body. **Dialog helper and error text, buttons**: Label.
- **Commands and tokens** in the agents dialog: Label size (13px/400/1.4) in the 02.1 Mono stack.

## Interaction Contracts

### Forest bar and entry points (D-18)

| Trigger | Behavior |
|---------|----------|
| App launch with remembered trees | Each tree reopens at its remembered frame position; canvas restores the last view; the forest bar sits at top 16px / left 16px with 8px gaps |
| First launch after this phase with no stored user name | Name prompt opens before the canvas accepts input; Escape does nothing; Continue saves to settings |
| Add tree > Add Obsidian Vault... | Native folder picker; after selection, Add vault dialog; on Add vault, a new frame is placed 64px right of the rightmost frame, top-aligned with it, and the canvas pans so the new frame is centered |
| Add tree > Open Tapestry World... | Native open dialog for `.tree`; same placement rule |
| Add tree > New Tapestry World... | Existing save dialog flow (carried), then same placement rule |
| Double-click empty canvas outside all frames with no trees open | Carried Phase 2 behavior: save dialog, new world frame at the click position |
| Double-click empty canvas outside all frames with trees open | Nothing is created (UA-06); no notes exist outside frames |
| Name button | Opens the Change your name dialog |
| Agents button | Opens AgentsPanel as a popover under the button (same surface as PassageChooser, min width 320px); click outside or Escape closes it |

The old top-left SaveIndicator is removed from the window corner; its states render in each native frame's header status slot.

### Tree frames (D-15, D-16, D-17)

| Trigger | Behavior |
|---------|----------|
| Pointer down on frame header (not on a button) and drag | Whole frame moves with its notes, groups and connections; frame shows being-dragged style |
| Frame drag end | If the frame is within 64px of another frame, the other frame is pushed away along the axis needing the smaller move, repeated until no frames overlap; final positions save to settings |
| Click frame header | Selects the frame (2px accent outline); Delete key does nothing on frames |
| Note dragged inside its own frame | Carried note drag; frame bounds grow to fit on drop (push-apart rule applies) |
| Note dragged over another tree's frame | Target frame shows copy drop target style; cursor `copy`; a label chip "Copy to [tree name]" follows the pointer |
| Note dropped on another tree's frame | Original snaps back to its position; a copy appears at the drop point connected by a grew-from line (D-17). Native to vault with lossy content opens the Lossy copy dialog first; Cancel removes the pending copy |
| Note dropped outside every frame | Treated as a drag within its own frame; the frame grows to include it |
| Tree options > Close tree | Frame is removed from the space immediately, no confirmation; cross-tree lines to it become remote stubs in other frames |
| Tree options > Show in Finder | Reveals the `.tree` file (native) or vault folder (vault) |

### Folder groups (D-26, D-27)

| Trigger | Behavior |
|---------|----------|
| Drag group label | Moves the group and its notes inside the frame (Tapestry position only, no file write) |
| Note dragged over another group | Target group shows move drop target style, or refused style if the name collides |
| Note dropped into another group | Note moves; header status "Writing [file]..."; the file moves to that folder |
| Note dropped in the frame outside any group | File moves to the vault root |
| Double-click empty space inside a group | New vault note `Untitled.md` in that folder; title input focused and selected |
| Double-click empty frame space outside groups | New `Untitled.md` in the vault root |

### Vault note editing (D-10, D-12, D-22, D-28)

| Trigger | Behavior |
|---------|----------|
| Click into vault note body | Plain-text editing of the file's exact text (UA-04); formatting toolbar does not appear |
| Typing | Edit commits to the vault tree as `human user.<name>`; header "Writing soon..."; 1s after typing pauses, "Writing [file]..." |
| Retitle and press Enter or blur | Valid: file renamed, footer path updates. Invalid: validation line, title reverts |

| Undo (Cmd/Ctrl+Z) with no editor focused, vault frame selected | Compensating write of the previous text; a D-23 group undoes as one step |

### Placeholder notes (D-34)

| Trigger | Behavior |
|---------|----------|

| Escape before typing | Leaves edit mode; nothing is created |

### Connections

| Trigger | Behavior |
|---------|----------|

| File note Open file | Opens the file with the OS default app |
