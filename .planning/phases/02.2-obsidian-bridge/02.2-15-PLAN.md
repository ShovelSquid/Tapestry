<objective>
Trees in one space can be connected to each other. A connection between notes in different trees is recorded in both journals, each tree holding its own end and naming the other (D-16). Deleting a note cuts its cross-tree connections in every tree, and everything stays in history (D-25). A crash between the two commits is repaired honestly.

Purpose: the forest is more than side-by-side islands. The cross-tree reference shape is costly to change, so it is fixed and documented here with crash safety.
Output: ForestCommands (connect, cut, repair), a commit observer, a reconcile guard, cross-frame drawing, RemoteStub, and the reader's guide section.

    connectAcrossTrees(actor, { from: { tree, note }, to: { tree, note }, label?: string, kind?: 'cross-tree' | 'grew-from' }): CommandResult<{ pair: string; fromEdge: string; toEdge: string }>.
    1. Resolve both trees. Their ids must differ and both journals must be Ok. Both notes must be live and must not be stubs.
    2. Set pair = crypto.randomUUID() and edge label = kind ?? CROSS_TREE_LABEL.
    3. Title of a note: its title property for Tapestry notes, or the basename of md.path without .md for vault notes.
    4. Commit the target tree first. Call prepareWrite, take next = getNextIds(), and submit:
       - a createNode of REMOTE_STUB_TYPE with props remote.tree (source id), remote.name (source name), remote.node (from.note), remote.title (source title), remote.path (source path), remote.pair (pair);
       - a createEdge from next.node (the stub) to to.note with the label, plus a tapestry.label text prop when a label is given.
       Use message `connect ${to.note} to ${sourceName} · ${sourceTitle}`.
    5. Commit the source tree second, the mirror image: a stub naming the target and an edge from from.note to the stub, with message `connect ${from.note} to ${targetName} · ${targetTitle}`.
    6. If the second commit fails, return its error; repair in Task 3 removes the orphan.
    7. Call hooks.onCommitted for both trees.
    Keep the grew-from direction convention: for kind grew-from the new copy is the `from` side.
