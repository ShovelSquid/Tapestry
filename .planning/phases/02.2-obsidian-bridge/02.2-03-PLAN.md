<objective>
Agents reach a Tapestry world over MCP. Claude Code launches `tapestry-mcp` (stdio). The shim forwards each tool call over a 0600 Unix socket to the Electron main process, where the agent's token becomes `agent.<name>` (D-06). The shared note command layer then enforces the grew-from rule (D-04) and commits. This plan introduces that command layer (D-01) and the tree registry. The renderer refreshes when an agent writes.

Purpose: this is the agent-bridge tracer, ordered first per D-01. Tapestry stays the only writer of .tree files because the journal's flock admits one writer (RESEARCH Pattern 2).
Output: TreeRegistry, NoteCommands (create_note, read_note, list_trees), AgentRegistry, AgentSocketServer, the MCP shim built to out/main/mcp.js, and tests that drive the real shim over stdio.

Decisions within Claude's Discretion (recorded):
- Transport is stdio shim + Unix socket. There is no TCP listener, and no web server in packaged operation.
- The `grew-from` edge runs from the new note to its parent, so it reads naturally in the file: `create-edge e5 n13 n12 grew-from`, meaning n13 grew-from n12.
- An agent-created note body is stored as editor JSON (D-12).
- ChatGPT (public HTTPS / Secure MCP Tunnel) is not scheduled in 2.2 (see 02.2-12-PLAN.md and COVERAGE.md).
</objective>
