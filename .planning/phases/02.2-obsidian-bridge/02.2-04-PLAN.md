<objective>
This plan completes the agent bridge. Agents get a small, clear tool set: read, search, grow, edit, rename, delete and connect (D-03). They may change or delete only notes they created, using authorship from the history index (D-05), but may connect any notes. Kaelen connects and removes agents from an Agents panel, and each agent is visibly and distinctly attributed (D-06). If an agent writes into a tree that Kaelen has rewound, the change is surfaced rather than failing silently (UA-14).

Purpose: after this plan, the MCP half of D-01 is finished and usable end to end from Claude Code.
Output: full tool set with policy tests, ConnectionCommands, connect-command builder, agents IPC, ForestBar, AgentsPanel, ConnectAgentDialog, TransientNotice.

Recorded semantics: undo in native trees is replay navigation (kernel-bridge.ts). Discarding redo therefore returns the view to the latest state before the agent's commit is appended. The UA-14 copy is kept verbatim. connect_notes takes tree-qualified endpoints. In this plan both endpoints must be in the same tree, and Plan 13 adds cross-tree endpoints without changing the schema.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent (possibly prompt-injected) -> tool calls | Model output drives update/delete requests |
| renderer -> agents IPC | UI creates and removes credentials |
| clipboard / terminal | The one-time token leaves the app through a command |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.2-18 | Tampering | update/rename/delete tools | high | mitigate | assertOwnNote compares the calling actor with createdBy from the journal-derived history index; refusals commit nothing (notes-policy.test.ts); deletes remain restorable through history |
| T-02.2-19 | Spoofing | removed agent's token | high | mitigate | AgentRegistry.remove deletes the stored hash so verify returns null; socket refuses the next request |
| T-02.2-20 | Information Disclosure | token in command / clipboard | medium | accept | Token is shown once and never stored in plaintext; the dialog states the risk and recovery (remove and reconnect); local terminal history is under the user's control |
