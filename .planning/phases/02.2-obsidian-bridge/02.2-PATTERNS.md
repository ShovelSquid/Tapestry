## Pattern Assignments

### `app/src/main/kernel-bridge.ts` (MOD) and `app/src/main/trees/registry.ts` (NEW)

**Analog:** `app/src/main/kernel-bridge.ts`

**Lifecycle: open-first-then-release (lines 97-128)** — copy into registry `open(path)` so a failed open never drops an already open tree; each tree gets its own `KernelBridge` (own flock):
```typescript
open(path: string): void {
  const target = resolve(path)
  if (this.instance && this.openPath === target) {
    this.close()
  }
  const next = TapestryAddon.open(path)
  this.close()
  this.instance = next
  this.openPath = target
  this.syncCurrentSeq()
}
```

**Rewound guard (lines 149-164)** — keep; vault trees must never rewind (RESEARCH Pattern 5, Pitfall 10):
```typescript
if (this.currentSeq !== (this.instance.getLastSeq() as number)) {
  throw new Error(
    'Cannot commit while history is rewound; redo to the latest change or discard the undo first',
  )
}
const result = this.instance.submit(actorKind, actorId, message, ops)
```

**IPC registration (lines 263-313)** — today a static singleton; this is what changes. The current `kernel:submit` takes actor from the renderer (the hole to close):
```typescript
ipcMain.handle('kernel:submit', (
  _event: any, actorKind: string, actorId: string, message: string, ops: OpObject[],
) => {
  return bridge.submit(actorKind, actorId, message, ops)
})
```
New shape: `ipcMain.handle('kernel:submit', (_e, treeId, message, ops) => commands.submitAsHuman(treeId, message, ops))`, with the registry resolving `treeId` and `actor.ts` stamping `human user.<name>`. Keep the `{ ok: ... }` result convention used by `kernel:undo/redo`.

**Types to reuse (lines 51-83):** `OpObject`, `CommitResult`, `NodeData`, `EdgeData`, `JournalStatus` — export them rather than redefining in commands/.

```typescript
function getLastOpenedPath(): string {
  return join(app.getPath('userData'), 'last-opened.json')
}

function readLastOpened(): string | null {
  const filePath = getLastOpenedPath()
  if (!existsSync(filePath)) return null
  try {
    const data = JSON.parse(readFileSync(filePath, 'utf-8'))
    if (isWellFormedTreePath(data.path) && existsSync(data.path)) {
      return data.path
    }
  } catch {
    // Corrupted or unreadable — treat as no last file
  }
  return null
}
```

## Shared Patterns

### Actor stamping (all write paths)
**Source:** `app/src/main/kernel-bridge.ts:149` (single write path) + `plugin-host.ts:331,785` (sites to close)
**Apply to:** kernel IPC, plugin facades, socket server, reconciler, writer. No actor parameter crosses IPC, plugin API or MCP schema; main stamps from channel.

### Result/error shape
**Source:** `plugin-host.ts` lines 736-800
**Apply to:** command layer, socket server, MCP tool results: `{ ok: true, ... } | { ok: false, error: string }`, error text via `err instanceof Error ? err.message : String(err)`.

### Input validation of untrusted strings
**Source:** `plugin-host.ts` 33-43, `index.ts` 92-115 (`isWellFormedTreePath`, `validateTreePath` with home/approved-path check)
**Apply to:** tree paths, vault-relative `.md` paths (no `..`, no absolute), agent names, note titles (D-28 forbidden chars).

### Failure containment
**Source:** `index.ts` `loadPluginsSafely` (118-124), `kernel-bridge.ts` `close()` try/catch with `console.error('[KernelBridge] ...')`
**Apply to:** watcher, socket server, reconciler startup. Log prefix convention `[Component]`. In the MCP shim never log to stdout (use stderr).

### userData JSON persistence
**Source:** `index.ts` 54-81
**Apply to:** settings.json, agents.json.
