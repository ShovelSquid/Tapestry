  <action>

    In registry.ts add interface UnavailableTree { id: string (`path:${resolvedPath}`); name; kind; path; vaultRoot?; status: 'damaged' | 'locked' | 'missing'; reason: string }. Add tryOpen(path, opts), which returns OpenTree | UnavailableTree:
    - A thrown error containing "locked" becomes status locked.
    - A missing file (existsSync false, or detail naming Missing) becomes status missing.
    - Any other open failure becomes damaged with the error detail.

| T-02.2-29 | Tampering | damaged journal writes | high | mitigate | tryOpen closes a non-Ok journal and records it unavailable; resolveTree refuses writes; no automatic repair (registry.test.ts) |

| T-02.2-32 | Repudiation | silently dropped trees | medium | mitigate | Unavailable entries stay listed with status and reason until the user chooses Close tree |
