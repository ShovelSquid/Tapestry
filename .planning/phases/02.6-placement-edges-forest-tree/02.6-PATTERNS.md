const settleFrames = (movedTreeId: string) => {

**Source:** `app/src/main/commands/actor.ts` lines 126-136 @8c4e219 (`OBSIDIAN_BRIDGE_ACTOR`, `SYSTEM_ACTOR`) and `kernel-bridge.ts` `submitAs` (216-218).
**Apply to:** every forest and home commit. Main stamps actors, and no IPC argument carries one. Human = `getHumanActor()` in `index.ts` (it throws `'Set your name before making changes'`, and the error is returned as `{ ok: false, error }`). System = `SYSTEM_ACTOR`.

### IPC result shape and validation
**Source:** `index.ts` `trees:*` handlers, lines 460-566 @8c4e219.
**Apply to:** `trees:moveFrames`, `trees:fitFrame`, `trees:undoFrames`, and changed `open/create/close/reopen`, `vault:add`. Args are typed `unknown`, checked with `typeof`/`Number.isFinite`, the result is `{ ok: boolean; error?: string; treeId?: string }`, and errors go through `errorMessage(err)`. Never throw across IPC.

### Untrusted file input
**Source:** `settings.ts` header (lines 8-11) and `isSafeAbsolutePath` (58-60); `index.ts` `isWellFormedTreePath` (89-95).
**Apply to:** the settings pointer, forest `path.hint`, `vault.root.hint`, and the migration input.

### Open without repair
**Source:** `registry.ts` `tryOpen` (lines 200-253 @8c4e219). It never repairs and closes a non-Ok bridge at once.
**Apply to:** opening the forest and home trees (migrate cases E/F/G/H).

### Real addon in tests, with flock cleanup
**Source:** `app/test/helpers/temp-tree.ts`; `registry.test.ts` lines 23-49.
**Apply to:** all `space/*.test.ts`. Use distinct world names, close every bridge in `afterEach`, and inject every path.

### Comment voice
Every analog has a file doc comment giving the *why* with decision IDs (D-xx, T-xx), `// ----` section banners, and short `/** */` comments on each export. New files follow this.
