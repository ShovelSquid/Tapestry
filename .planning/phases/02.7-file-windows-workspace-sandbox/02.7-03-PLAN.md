## Phase Goal

**As** Kaelen, **I want** the file window to follow its folder live — edits by Claude Code's own tools, by git, and by any editor appear in the window moments later with honest authorship — **so that** the window always shows what the files say, whoever changed them.

<objective>
Expansion: outside changes (D-06), carried from catch-up on open (Plan 01) to live watching.

Purpose: during the dogfood, Claude Code also edits with its built-in tools, and git checkouts rewrite files. Without a watcher the window goes stale until the next launch.

Output:
- `mirror/watcher.ts` and `mirror/quiet-queue.ts`: generic, for 02.2 Plan 10 to reuse instead of writing obsidian-only copies;
- live reconciles with a stat cache and seq guard;
- self-healing watch errors with a header status;
- the `workspace.bridge` author-unknown badge;
- Retry write;
- the scale work.

Recorded choices:
- **Watcher: `fs.watch(root, { recursive: true })`, not chokidar.** It needs no new dependency, and so no package-legitimacy gate. Electron 32 runs Node 20.18, where recursive watching on macOS is native FSEvents and never follows symlinked directories. The watcher is only a hint; the hash-based reconciler decides what changed (02.2 RESEARCH Pattern 3). `FolderWatcher` is an interface, so 02.2 Plan 10 may put chokidar 4.0.3 behind it if a vault needs it.
- **A moment:** 750 ms of quiet, forced after 5 s. These are 02.2 Plan 10's values for D-23, which D-06 reuses.
- **Watch errors restart themselves after 5 s** with a full catch-up, rather than asking for a click. The header says "Not watching" until the restart.
- **IPC stays whole-tree.** Payloads are not trimmed here: getNodes still carries every file's text. If the backstop check finds refreshes laggy on this repo, lazy text over IPC is the next step, as a gap-closure plan.
- **Reopen cost is measured, not fixed.** The spike finding is that `Kernel::fromJournal` copies the world per commit. The scale test records reopen time after 200 edits so the risk is visible in the SUMMARY. The fix belongs to the kernel (Phase 3 snapshots).
</objective>

**app/src/main/mirror/quiet-queue.ts** implements exactly the 02.2 Plan 10 contract, so the vault can import it.
- Exports `QUIET_MS = 750`, `MAX_WAIT_MS = 5000` and `class QuietWindowQueue`.
- Constructed with `({ onFlush: (paths: Set<string>) => Promise<void>, quietMs?, maxWaitMs?, now?, setTimer?, clearTimer? })`.
- `add(paths)` merges paths, restarts the quiet timer, and schedules an immediate flush once `now() - firstPendingAt >= maxWaitMs`.
- Flushes are serialized. Paths added during a flush wait for the next one.
- Also exports `flushNow()` and `dispose()`.

quiet-queue.test.ts, with vi.useFakeTimers:
- adds at 0, 300 and 600 ms flush once at 1350 ms with all the paths;
- adds every 500 ms flush by 5000 ms;
- a flush in progress defers new paths to a second flush.

**app/src/main/mirror/watcher.ts** exports `interface FolderWatcher { close(): void }` and `createFolderWatcher(root, { onDirty(rels: string[] | 'all'): void; onError(err: Error): void, isNoise?(rel): boolean }): FolderWatcher`.
- It uses `fs.watch(root, { recursive: true, persistent: true })`.
- Each event's filename becomes a posix rel. A null filename becomes 'all'.
- Default noise dropped before onDirty:
  - a first segment equal to .git (case-insensitive), or any `/.git/` segment;
  - a first segment `node_modules`;
  - any segment containing TAPESTRY_TMP_MARKER.
- Every other rel is passed along with its parent folder rel.
- The watcher's 'error' event calls onError.
- A header comment states that this is a hint only and that fs.watch on macOS (FSEvents) does not traverse symlinked directories.

**workspace-service.ts.**

`reconcileNow(treeId, hints: Set<string> | 'all'): Promise<ReconcileStats { listed, read, reused, commits }>`. It becomes the single reconcile path, and catchUp(treeId) = reconcileNow(treeId, 'all').
- It keeps the per-tree serialization, the missing-root refusal, the 20000-file limit and the lastGoodSeq guard.
- Stat cache, per tree: `Map<rel, { size, mtimeMs, ino, state: PathState }>`. An entry whose lstat (size, mtimeMs, ino) is unchanged and whose rel is not hinted, when hints is not 'all', reuses its cached state; every other entry is re-read with readPathState.
- A first import after a fresh open has an empty cache and so reads everything.
- The model is assembled from those states, then planMirror and commit as before.
- Move the multi-commit message tagging into an exported pure `groupMessages(base, count, stamp): string[]` in mirror/plan.ts (one message unchanged, several tagged `(group <stamp>, i of n)`), and use it here.

Watching:

- `stopWatching(treeId)` disposes both.
- `stopAll()` stops every watcher.
- The constructor option `createWatcher` exists so tests can inject a fake watcher.
