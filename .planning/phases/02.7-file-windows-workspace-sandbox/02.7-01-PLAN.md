**app/src/main/mirror/fs.ts** (new). Move the markdown-agnostic code out of vault-fs.ts.

- `FolderEntry { rel, kind: 'dir' | 'file' | 'symlink', size, ino, mtimeMs }`.
- `walkFolder(root, isIgnored: (rel) => boolean): Promise<FolderEntry[]>`. This is walkVault's algorithm with the ignore predicate as a parameter: lstat only, symlinks recorded and never followed, sorted by rel.
- `entriesFromPaths(root, rels): FolderEntry[]` (sync).
  - It lstats each listed rel and skips any that no longer exist.
  - A listed rel that is a directory, such as a submodule gitlink, is skipped rather than descended.
  - It adds one `dir` entry for every ancestor folder of a listed file, and sorts the result.
- `isGitWorkTree(root): boolean` runs execFileSync('git', ['-C', root, 'rev-parse', '--is-inside-work-tree']). It is true only when the output is `true`; a missing git or a non-zero exit is false.
- `listGitFiles(root): { kind: 'git'; rels: string[] } | { kind: 'not-git' }`.
  - When isGitWorkTree(root) is false, return not-git.
  - Otherwise run execFileSync('git', ['-C', root, 'ls-files', '-z', '--cached', '--others', '--exclude-standard']) with a 20 s timeout and a 64 MiB maxBuffer. Split the output on NUL, drop empty entries, and dedupe.
  - A failure after the work-tree check throws an Error whose message names git's stderr. It must never return an empty list, because an empty list would read as "every file was deleted".
- `isGitIgnored(root, rel): boolean` runs execFileSync('git', ['-C', root, 'check-ignore', '-q', '--', rel]). Exit 0 returns true, exit 1 returns false, and any other exit throws (fail closed). Without --no-index, check-ignore never reports a tracked file as ignored, which is exactly the "git would show it" rule.
- `readBoundedBytes(root, rel, maxBytes = MAX_MIRROR_READ_BYTES)`:
  - open with `fs.constants.O_RDONLY | fs.constants.O_NOFOLLOW`;
  - fstat, and if the size is over maxBytes return `{ tooLarge: true, size }` before allocating;
  - otherwise read the bytes and return `{ bytes, sha256 }`.
- `decodeText(bytes)` is decodeMarkdown's body, unchanged: NUL, fatal UTF-8 and the 1 MiB line limit, with reasons in words.
- `sha256Hex(data)`.
- `MAX_MIRROR_READ_BYTES = 16 * 1024 * 1024`.

**app/src/main/mirror/atomic-write.ts** (new).
- `TAPESTRY_TMP_MARKER = '.tapestry-tmp'`.
- `writeFileAtomicSync(abs, text, opts?: { mode?: number })`:
  1. Take the mode from `opts.mode`. Otherwise use the existing target's mode (lstat, a regular file only, masked with 0o7777). Otherwise use 0o644.
  2. Create `.<basename>.tapestry-tmp-<pid>-<8 random hex>` in the target's folder with openSync(tmp, O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW, mode). O_EXCL never follows a link.
  3. Write the UTF-8 bytes in full, then fsyncSync, closeSync and renameSync(tmp, abs). The rename replaces the directory entry, never a link's target.
  4. On any error, unlink the temp file (ignoring ENOENT) and rethrow.

**app/src/main/mirror/plan.ts** (new). A pure planner (no kernel, no Electron) parameterised by a shape.

Types:
- `MirrorShape { textType, fileType, folderType, keys: { path, text, sha256, ext, bytes, unreadable }, layout: MirrorLayout }`, where `MirrorLayout { columns, columnStep, rowStep, labelHeight, groupGap, textCardWidth, fileCardWidth }`.
- `PathState = { kind: 'absent' } | { kind: 'folder' } | { kind: 'text'; text; sha256 } | { kind: 'file'; ext; bytes; sha256?; unreadable? }`.
- `MirrorModel { folders: Set<string>; paths: Map<string, PathState> }`.

Reading:
- `readPathState(root, rel): PathState` (sync):
  - an lstat ENOENT is `absent`;
  - a symlink is `file` with unreadable 'symbolic link not followed';
  - a directory is `folder`;
  - a regular file goes through readBoundedBytes. Too large is `file` with unreadable `is larger than 16 MiB (<n> bytes)`. If decodeText succeeds it is `text`; otherwise it is `file` with the reason and sha256.
- `buildMirrorModel(root, entries, onProgress?)`: the same classification, async over FolderEntry[].

`planPathChange(tree: { nodes: NodeData[] }, rel, state, shape): { ops: OpObject[]; change: 'created' | 'modified' | 'deleted' | null }`. This is the single source of per-path ops.
- An absent path with an existing node becomes deleteNode.
- A text state with a text node emits setProperty text and sha256 only when the stored sha256 differs.
- A file state emits setProperty for changed ext/bytes/sha256/unreadable and unsetProperty for a stale unreadable.
- A change between text and file emits deleteNode, then createNode of the new type at the old node's position.xy.
- A missing node emits createNode, preceded by one folder createNode for every ancestor folder the tree lacks (outermost first).

`planMirror(tree, model, shape): { ops: OpObject[][]; summary: { created, modified, deleted } }`:
- A full reconcile built from planPathChange for every model path (sorted), then a deleteNode for every shape node whose path is in neither model.paths nor model.folders.
- Chunk by text bytes at `MAX_COMMIT_TEXT_BYTES = 32 * 1024 * 1024`.
- Positions:
  - when the tree has no node of the shape's types (first import), positions come from `layoutFolderGrid(model, layout)`. That is layoutVault's algorithm with a column count and one spare row (groupGap) between groups, so a group can grow by a row without covering the next;
  - otherwise a new node goes in the next grid slot after its folder's existing children, and a new folder goes below the lowest existing node plus groupGap.
- Text nodes carry width textCardWidth; file nodes carry fileCardWidth.

Messages:
- `describeMirrorChanges(summary)` returns `observed change to <rel>` for exactly one modified path. Otherwise it returns `observed changes: created a, b; modified c; deleted d` (empty parts omitted).
- `groupStamp()` returns a whole-second ISO stamp.

`resolveWorkspaceTarget(lookup, args: { workspace?: string; path: string }, mode: 'read' | 'write'): CommandResult<WorkspaceTarget>`. Rules, checked in this order; each refusal returns `{ ok: false, error }`:
1. No open workspace: return exported `NO_WORKSPACE_MESSAGE` = "No workspace is open in Tapestry. Open one with Add tree > Add Workspace Folder...; file tools never use any other folder."
2. `args.workspace` given: match an open workspace by exact tree id or case-insensitive name. No match: `<ref> is not an open workspace`. Two matches: `Workspace name <ref> is ambiguous; use the tree id`.
3. The path is empty or contains NUL or a backslash: `path must name a file inside the workspace, with / between folders`.
4. Absolute path: it must lie under root or realRoot, compared with path.relative, where a `..` prefix or an absolute result means outside.
   - Outside a named workspace: `<path> is outside the workspace <name> (<root>)`.
   - With no workspace named, pick the open workspace with the longest containing root, or refuse `<path> is outside every open workspace`.
5. Relative path with no workspace named: exactly one open workspace is used. With several: `Several workspaces are open (<names>); pass workspace`.
6. Split the rel on `/` and drop `.` segments.
   - An empty segment or an empty result (the root itself): `path must name a file inside the workspace, not the workspace itself`.
   - Any `..` segment: `<path> uses '..'; paths must stay inside the workspace`.
   - Any segment equal to .git, compared case-insensitively: `<path> is inside .git; file tools never read or write git's own files`.
   - Any segment containing TAPESTRY_TMP_MARKER: `<path> is a Tapestry temporary file`.
7. Walk from realRoot one segment at a time with lstatSync.
   - Any existing segment that is a symbolic link: `<prefix> is a symbolic link; file tools never follow links`.
   - An existing non-final segment that is not a directory: `<prefix> is not a folder`.
   - A missing segment: in read mode `<path> does not exist in <name>`; in write mode the rest may be created later.
   - The final entry: a directory is refused as `<path> is a folder, not a file`.
8. Mirror eligibility. In a git workspace, isGitIgnored(root, rel) true means `<path> is ignored by git in <name>; file tools reach only files the window shows`. Outside git, isIgnoredWorkspacePath(rel) true gives the same message.
9. Success returns `{ rel (posix, as the user spelled each existing segment), abs = join(realRoot, ...segments), exists }`.

**app/src/main/workspace/workspace-service.ts** (new). `WorkspaceService implements WorkspaceLookup`, constructed with `(registry, { treesDir, hooks?: CommandHooks })`.

    - a first import reads `observed workspace <name>: <t> text files, <f> other files, <d> folders`;
    - otherwise the message is describeMirrorChanges;

  1. Read readPathState(ws.realRoot, rel).
  2. Get planPathChange against the current nodes. If it yields ops, submit them as WORKSPACE_BRIDGE_ACTOR with describeMirrorChanges of that one change (`observed change to <rel>`, or `observed changes: created <rel>` / `deleted <rel>`), then call onCommitted.
  3. Return the state.
- `commitWrite(actor, target, text, message): { note, seq, sha256 }` (sync):
  1. Require `tree.bridge.status().kind === 'Ok'`, otherwise throw `<name>'s tree is damaged; Tapestry will not write to it`.
  2. Call prepareWriteFor(tree, actor, hooks).
  3. Call writeFileAtomicSync(target.abs, text).
  4. Build the ops with planPathChange for `{ kind: 'text', text, sha256: sha256Hex(text) }`, submitAs(actor, message), call onCommitted, and return the note id (the existing node id, or the nodeIds entry for the created text node).

**app/src/main/commands/file-tools.ts** (new). `WorkspaceFileCommands`, constructed with `(workspaces: WorkspaceService)`. Every method is synchronous and returns CommandResult; none ever throws.

`readFile({ workspace?, path, offset?, limit? })`:
1. resolveWorkspaceTarget in read mode, then readPathState.
2. A non-text state is refused as `<path> is not a text file (<reason or 'binary'>); Tapestry shows only its name and size`.
3. Split the text on `\n`, keeping any `\r`. Return lines offset through offset+limit-1, with offset defaulting to 1 and limit to 2000, joined with `\n`.
4. Return `{ workspace: name, path: rel, note: id or null, text, sha256, totalLines, startLine, endLine }`.

Reading never commits.

`editFile(actor, { workspace?, path, old_string, new_string, replace_all? })`. Every refusal happens before anything is committed or written:
1. Resolve in write mode. A missing target is refused as `<path> does not exist in <name>`.
2. Read the disk with readPathState; this does not commit. A non-text state is refused as above.
3. Refusals on the strings:
   - `new_string must differ from old_string`;
   - `old_string was not found in <path>`;
   - `old_string occurs <n> times in <path>; add surrounding lines to make it unique, or pass replace_all`, unless replace_all is set.
4. Replace the old_string occurrences (one, or all with replace_all) and validate the new text:
   - no NUL: `text must not contain NUL`;
   - it must round-trip through Buffer.from(text, 'utf-8').toString('utf-8') unchanged: `text must be valid Unicode (it contains an unpaired surrogate)`;
   - no line over 1 MiB: `text has a line longer than 1 MiB`;
   - at most MAX_WORKSPACE_WRITE_BYTES: `text must be at most 4194304 bytes`.
5. Only now call observePath, the D-06 observe-first step, which commits any disk state the tree has not recorded. If the state it returns differs from the one read in step 2 (the file changed in between), recompute from the new text and apply the step 3 refusals again.
6. Call commitWrite(actor, target, next, `edit <rel> (<n> replacement|replacements)`) and return `{ workspace, path, note, seq, sha256, replacements }`.

Wrap every step in try/catch that returns `{ ok: false, error: message }`. Every refusal returns before any write or commit.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP shim → agent socket → runAgentTool | Tool arguments (paths, strings) come from a model and a replaceable local process; never trusted |
| renderer → main (workspace:add, workspace:saveFile) | The window may send any value; main decides roots and paths |
| workspace folder contents → mirror | Other processes (git, editors, other Claude sessions) write the folder concurrently; symlinks and huge files are possible |
| main → git subprocess | Arguments cross into a child process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02.7-01 | Elevation of Privilege | resolveWorkspaceTarget (`..`, absolute outside root) | high | mitigate | Any `..` segment is refused, and absolute paths must be path.relative-inside root or realRoot. Tested in sandbox.test.ts, with byte hashes of the parent temp dir (including `outside/`) unchanged |
| T-02.7-02 | Elevation of Privilege | symlinks along the path, symlink swap at the final component | high | mitigate | Every existing segment is lstat'ed from realRoot and any symlink refused. Reads open with O_NOFOLLOW. The temp file opens with O_CREAT and O_EXCL plus O_NOFOLLOW, and rename replaces the entry, never a link target. Residual: a local process with write access to the root could swap a parent folder between check and rename — accepted, because that process can already write the folder |
| T-02.7-03 | Tampering | writes into .git (hooks lead to code execution) | high | mitigate | A .git segment in any letter case is refused before any filesystem access. The mirror never lists .git |
| T-02.7-04 | Information Disclosure | read_file of ignored secrets (.env) or files outside the root | medium | mitigate | Reads use the same resolver. Git-ignored paths, and the non-git ignore rules, are refused (sandbox.test.ts .env case) |
| T-02.7-05 | Spoofing | agent claiming another identity | high | mitigate | ReadFileArgs and EditFileArgs are .strict() with no actor field, and the actor comes from the verified token (agentActor(name)). The shim test asserts no actor property |
| T-02.7-06 | Repudiation | outside change credited to an agent or person | medium | mitigate | observePath commits any unrecorded disk state as plugin workspace.bridge before a Tapestry write (workspace.test.ts observe-first case) |
| T-02.7-07 | Tampering | renderer-supplied path in workspace:saveFile | high | mitigate | Main reads file.path from the tree node and validates the node type, and the path still goes through resolveWorkspaceTarget. The renderer supplies only ids, text and a base hash, each shape-checked |
| T-02.7-08 | Tampering | workspace:add with a fabricated root | high | mitigate | Only roots approved through the native folder dialog this session, or restored from settings, are accepted. The root must be an lstat directory, not a symlink, and not / or the home directory |

| T-02.7-10 | Denial of Service | huge files, huge folders, huge writes | medium | mitigate | fstat before allocation with a 16 MiB read cap, a 4 MiB write cap, a 20000-file limit per workspace, and commits chunked at 32 MiB of text |
