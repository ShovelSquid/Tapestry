## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App state and vault path entry → canonical vault root | Local persisted state and a user-entered folder path choose the filesystem tree the app reads. |
| Filesystem and watcher callback → vault worker → UI snapshot | Note paths and event notifications cross into the serialized index pipeline. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | VaultSelection and root switch | medium | mitigate | Canonicalize the root, validate readability before replacing active state, use index-relative note paths, and retain the last valid snapshot on failure. |
| T-02-02 | Denial of Service | Store/Watch worker and vault scan | medium | mitigate | Run all scan, classification, rescan, and index work off-frame on one serialized worker; publish only completed snapshots. |
| T-02-03 | Tampering | Store own-write classification | medium | mitigate | Reuse Store hash classification for watcher and fallback paths; suppress OwnEcho and serialize it with writes. |
</threat_model>
