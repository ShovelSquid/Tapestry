<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS keyboard events → ShellInput → hosted tool | Global shortcuts cross from platform input into shell routing and tool-specific handlers. |
| ShellInput raw-event filtering → terminal PTY | Untrusted key and text events may become commands executed by a local or remote terminal process. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Elevation of Privilege | Terminal PTY event forwarding | high | mitigate | Filter shell-owned shortcut Key and Text events in raw_input_hook before Terminal::take_input drains the frame; prove both event forms with input-router tests. |
| T-02-07 | Tampering | Global simulation shortcut dispatch | medium | mitigate | Make ShellInput the sole shortcut policy and gate simulation bindings on the active Simulation destination and keyboard focus. |
| T-02-08 | Denial of Service | Hidden terminal and editor state | medium | mitigate | Keep Ide and App owners alive across destination changes, avoid blocking tool switches on process startup, and test owner identity across hide/show transitions. |
</threat_model>
