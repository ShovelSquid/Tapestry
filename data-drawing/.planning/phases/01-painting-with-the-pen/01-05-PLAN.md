Validation (each failure: return the code, state untouched):
  StrokeBegin: start_tick == dd_tick else DD_ERR_TICK_MISMATCH; brush id in 1..brush_count else DD_ERR_BRUSH_ID; ordinal (bits 31..0 of stroke_id) != 0 and never seen before in this session (State keeps a sorted vector<uint64_t> seen_stroke_ids) else DD_ERR_STROKE_STATE; active count < DD_MAX_ACTIVE_STROKES else DD_ERR_LIMIT
  StrokeSamples: stroke active else DD_ERR_STROKE_STATE; 1 <= count <= DD_MAX_SAMPLES_PER_ACTION else DD_ERR_LIMIT; every sample.tick == dd_tick else DD_ERR_TICK_MISMATCH; indices: first == (last_sample_tick == tick ? last_sample_index + 1 : 0), each next == previous + 1, else DD_ERR_SAMPLE_ORDER; samples already this tick + count <= DD_MAX_SAMPLES_PER_TICK else DD_ERR_LIMIT; pressure <= DD_PRESSURE_MAX, |tilt| <= 90, twist <= 359, flags & ~7 == 0, pad == 0, else DD_ERR_SAMPLE_RANGE (new code 11)
  StrokeEnd: active else DD_ERR_STROKE_STATE; end_tick == dd_tick else DD_ERR_TICK_MISMATCH; the stroke leaves the active list; its nodes stay

Brush rule constants (rules/brush_body.hpp, pinned under DD_RULE_BRUSHBODY_VERSION = 1):
  DD_BODY_K = fx64::ONE (1.0)   DD_BODY_ZETA = fx64::ONE / 2 (0.5)
  k_t = div(DD_BODY_K, mass)    c_t = 2 * zeta * sqrt(k_t) = sqrt(k_t)
  validate_brush rejects unless 0 < k_t <= ONE and 0 < c_t <= ONE  (so mass >= 1 and mass <= 2^32 - 1 in integer terms; presets 1/4/16/64 pass)
  per tick with n samples: h = div(ONE, n) (n == 0 -> h = ONE with target = last target); per sample in index order:
    target = (from_q16(u), from_q16(v)); a = k_t*(target - x) - c_t*v; v += a*h; x += v*h  (velocity first, then position — symplectic)
  first sample of a stroke: x = target, v = 0, dir = (ONE, 0), path_accum = spacing (so node 0 emits at the pen-down point)
  direction update after each sub-step: if vx*vx + vy*vy >= DD_DIR_EPS (ONE >> 16) then dir = v / |v| (isqrt-based) else keep previous dir

Emission (rules/emit.hpp, pinned under DD_RULE_EMIT_VERSION = 1), per sub-step segment p0 -> p1 with the sample's pressure:
  seg = |p1 - p0| (sqrt of the Q32.32 squared length); carried = path_accum; remaining = seg; pos = p0
  if seg == 0: while carried >= spacing: emit at pos; carried -= spacing  (guard for the first node)
  else: while carried + remaining >= spacing: d = spacing - carried; f = div(d, remaining); pos = pos + (p1 - pos) * f; emit at pos; remaining -= d; carried = 0
  path_accum = carried + remaining
  emit at pos: Node { id = make_node_id(branch, ordinal, next_emission_index++), pos3 = origin + pos.u*right + pos.v*up, weight = curve_weight(brush, pressure), dir, velocity = v, tick = dd_tick, brush = brush id, scale_band = 0 }; inserted into state.nodes at its ascending-id position (lower_bound); when node_count == DD_MAX_NODES the emission is skipped deterministically
  curve_weight(brush, p): i = p >> 12 (0..15), frac = p & 4095, value = k[i] + (((k[i+1] - k[i]) * frac) >> 12) as u16, weight = from_raw(int64(value) << 16)   (identity knots: k[i] = i*4096 for i < 16, k[16] = 65535)
